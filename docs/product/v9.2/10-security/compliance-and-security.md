# v9.2 合规、安全与审计规范

## 1. 文档边界

本文件定义产品和工程控制，不替代正式法律意见。正式商用上线前，法务必须对适用法规、AIGC 标识方式、内容审核、版权/肖像授权、隐私与数据保留期限签署版本化评审结论；没有评审结论的规则只能用于测试环境。

## 2. 数据分级

| 级别 | 示例 | 控制 |
|---|---|---|
| L1 公开 | 已公开模板、公开作品信息 | 完整性、内容审核 |
| L2 内部 | 项目配置、普通任务状态、运营配置 | 鉴权、租户隔离、日志 |
| L3 敏感 | 未发布剧本/媒体、提示词、成本、合同、客户批注 | 加密、最小权限、导出审计 |
| L4 高敏 | 密码/验证码、身份材料、支付信息、供应商密钥、后台安全日志 | 强加密、专用访问、MFA、双人审批、严格脱敏 |

## 3. 认证安全

- 密码使用当前安全密码哈希算法及独立 salt，策略由安全配置管理。
- access token 短期有效，refresh token 旋转并检测复用。
- 后台员工强制 MFA；财务、合规放行和密钥操作再次验证。
- 验证码按目标、IP、设备和用途限流，不在日志保存明文。
- 登录失败响应不确认账号是否存在；风险登录产生安全事件和通知。
- 账号注销撤销所有会话，匿名化可删除身份字段，保留合法必要证据。

## 4. 应用安全基线

- 输入：服务端 schema 校验、长度限制、文件类型探测；不信任文件扩展名。
- 输出：HTML 上下文转义；富文本采用白名单清洗。
- SQL：参数化查询；动态排序仅允许白名单字段。
- CSRF：Cookie 会话接口使用 SameSite 和 CSRF token；Bearer API 不混用 Cookie 鉴权。
- SSRF：模型和媒体下载只允许受控域名或对象存储，解析后校验 IP，不访问内网地址。
- 上传：病毒/恶意文件扫描、媒体探测、摘要校验、隔离临时桶。
- 密钥：由密钥管理系统提供，数据库只保存引用；禁止进入代码、日志和前端。
- 依赖：锁定版本、SCA 扫描、镜像扫描和高危漏洞发布门禁。

## 5. 内容与权利合规对象

每个风险/授权记录至少包含：

- `targetType`、`targetId`、`projectSnapshotId`；
- `ruleCode`、`ruleSetVersion`、`riskLevel`；
- 证据摘要和受限证据对象；
- 来源、权利人、许可范围、地域、渠道、有效期；
- 模型供应商、模型、版本、生成时间、输入输出摘要；
- 责任人、处置状态、复核人与时间；
- AIGC 显式/隐式标识策略和实际执行结果。

## 6. 导出前检查清单

| 检查 | 阻断条件 | 解除方式 |
|---|---|---|
| 剧本/字幕/标题风险 | blocking 规则命中且未复核 | 修改内容或合规复核 |
| 图片/视频内容审核 | 高风险或审核失败 | 替换素材、重生或复核 |
| IP 改编权 | 商用项目未确认、过期或范围不含目标渠道 | 补充有效授权 |
| 真人/肖像 | 无授权或公众人物高风险 | 补充授权、替换形象或法务放行 |
| 音乐/音色/素材来源 | 来源缺失、禁止商用、许可过期 | 替换或补证 |
| AIGC 标识 | 项目/目标平台规则未配置 | 应用有效标识模板 |
| 模型记录 | 供应商、模型版本或调用证据缺失 | 修复记录或重新生成 |
| 项目版本 | 内容摘要与检查快照不一致 | 对新快照重新检查 |

正式导出 API 重新执行服务端门禁，不能依赖前端检查结果。

## 7. 风险等级

- info：提示，不阻断。
- low：建议修复，可由项目负责人确认。
- medium：商用导出前必须由合规角色确认。
- high：阻断正式导出，要求证据或内容修复。
- critical：冻结项目相关导出和公开能力，触发平台合规/安全事件。

规则版本变化不自动篡改历史结论；新导出按当前有效规则重新检查。

## 8. 人工复核与申诉

1. 申诉提交风险记录、理由和证据。
2. 系统锁定待复核快照，防止内容变化混入原申诉。
3. 复核人不能是原放行申请人；critical 需要两人审批。
4. 决定包含通过、拒绝、条件通过、要求补件。
5. 条件通过记录适用版本、渠道和有效期；超范围仍阻断。

## 9. AIGC 留痕

- 每个生成结果关联 ModelCallRecord、prompt/input digest、模型版本和时间。
- 成片 manifest 汇总所用镜头结果和模型记录。
- 显式标识位置、样式和持续时间按目标平台规则版本生成。
- 隐式标识/元数据记录执行方式和验证结果。
- 二次编辑和外部导入素材标记来源，不虚构为平台生成。

## 10. 审计

### 必审计动作

登录与安全、成员/权限、预算、付费任务、余额/退款/调账、项目冻结、内容审核、合规放行、权利证明、正式导出、客户确认、后台跨租户查看、密钥、模型上下线、配置发布和数据导出。

### 审计字段

actorType、actorId、sessionId、requestId、traceId、workspaceId、action、targetType、targetId、beforeDigest、afterDigest、reason、approvalId、IP、device、result、occurredAt、evidenceRef。

审计日志追加写、单独授权、定期归档并做完整性校验。普通管理员和数据库应用角色无删除权限。

## 11. 隐私与最小化

- 只收集完成账号、交易、审片和安全所需数据。
- 分析事件禁止包含完整剧本、提示词、媒体 URL、手机号、身份证明和支付凭证。
- 客户审片使用 viewerHash；没有必要时不要求客户注册平台账号。
- 管理后台默认脱敏，查看完整字段需要单独权限和业务原因。
- 数据导出和注销请求有身份核验、范围确认和审计。

## 12. 保留与删除策略

| 数据 | 默认策略 |
|---|---|
| 临时上传 | 未绑定 24 小时后清理 |
| 失败任务临时结果 | 7–30 天，按项目策略 |
| 已删除项目普通媒体 | 回收站 30 天后清理 |
| 正式交付/争议媒体 | 争议、合同或法务保留期内禁止清理 |
| 登录和安全事件 | 至少 180 天 |
| 账务、审计、合规证据 | 按法务批准的保留策略归档，不由普通业务删除 |

具体期限以法务评审版本和企业合同为准，通过配置执行；业务代码不硬编码不同客户的保留期。

## 13. 安全事件

事件级别：SEV-1 跨租户/密钥/资金风险，SEV-2 大范围数据或服务风险，SEV-3 局部可控风险。

流程：检测 → 限制影响 → 保存证据 → 通知负责人 → 修复 → 恢复 → 复盘。SEV-1 立即轮换相关密钥、撤销会话、冻结高风险写操作并保留审计。

## 14. 上线安全门禁

- 完成威胁建模和跨租户/IDOR 专项测试。
- 后台和高风险角色 MFA 生效。
- 密钥、日志、上传、预签名 URL 和回调验签通过测试。
- 账务、审计和合规表的应用角色无 UPDATE/DELETE。
- 正式导出合规阻断通过绕过测试。
- 数据备份恢复和安全事件演练完成。
- 法务对商用规则版本签字；未签字的外部正式发布功能保持关闭。
