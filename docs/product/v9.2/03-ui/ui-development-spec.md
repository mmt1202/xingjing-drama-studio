# v9.2 UI 开发规范

## 1. 适用范围

本规范将旧版视觉语言收敛为 v9.2 的工程实现标准，适用于创作者前台、团队后台、平台运营后台和客户审片 Web/H5。原型用于确认布局与业务信息，不要求复制原型中的通用模拟卡片。

## 2. 设计 Token

### 颜色

| Token | 色值 | 用途 |
|---|---|---|
| `--xj-bg-base` | `#07080C` | 页面背景 |
| `--xj-bg-surface` | `#12141B` | 卡片、表格 |
| `--xj-bg-panel` | `#171922` | 编辑和检查面板 |
| `--xj-bg-overlay` | `#1E212B` | 弹窗、下拉、悬浮层 |
| `--xj-line` | `#2A2E3A` | 边框、分割线 |
| `--xj-text-primary` | `#F5F6FA` | 主文字 |
| `--xj-text-secondary` | `#B8BECC` | 正文与说明 |
| `--xj-text-muted` | `#7E8494` | 辅助文字 |
| `--xj-brand-ai` | `#8B5CF6` | AI、选中、处理中 |
| `--xj-brand-create` | `#FF6B4A` | 主行动 |
| `--xj-success` | `#22C55E` | 成功，不作为品牌主色 |
| `--xj-warning` | `#F59E0B` | 警告、余额不足 |
| `--xj-danger` | `#EF4444` | 失败、违规、阻断 |
| `--xj-info` | `#3B82F6` | 普通信息 |

正文与背景对比度不低于 4.5:1；大字号不低于 3:1。状态不能只依赖颜色，必须同时包含图标、文字或形状。

### 字体与尺寸

- 中文：`PingFang SC`, `Microsoft YaHei UI`, `Noto Sans SC`, sans-serif。
- 英文和数字：`Inter`, `Roboto`, sans-serif。
- H1 28–32/1.25/700；H2 22–24/1.3/700；H3 18–20/1.4/600。
- 正文 14/1.6/400；辅助 12/1.5/400；标签不得小于 11px。

### 圆角、间距与层级

- 圆角：输入和按钮 10px，卡片 14px，大面板 18–22px，圆形头像 50%。
- 基础间距单位 4px；常用间距 8/12/16/20/24/32px。
- 阴影只用于悬浮层和可交互卡片；禁止大面积霓虹发光影响长时间工作。
- z-index 分层：基础 0，固定导航 100，下拉 300，抽屉 500，弹窗 700，通知 900。

## 3. 布局

### 创作者生产页

```text
左侧平台导航 72/220
  + 顶部上下文栏 56
  + 项目阶段栏 44（只在项目上下文）
  + 主工作区 min 720
  + 右侧检查器 320–380（可收起）
  + 底部时间线/批量栏 视页面出现
```

- 1440px 为最低主生产宽度；1728/1920px 优化多面板并列。
- 主工作区不得因右侧面板打开而小于 720px；不足时右侧面板改为抽屉。
- 平台首页不显示项目阶段栏；具体项目页面必须显示项目、剧集和当前阶段。

### 团队和平台后台

- 采用侧栏 + 顶栏 + 内容区布局。
- 数据表主导页面内容宽度可铺满；配置页正文最大宽度 1200px。
- 高风险操作始终使用独立确认弹窗，不放在行内快捷菜单首位。

### 客户审片

- 375–1920px 响应式。
- 移动端以播放器、版本信息和时间点批注为主，不展示生产参数。
- 横屏进入沉浸播放，仍保留退出、版本、水印和批注入口。

## 4. 基础组件

### 按钮

| 类型 | 用途 | 规则 |
|---|---|---|
| Primary | 每个视图唯一主行动 | 同一视觉区域最多一个 |
| Secondary | 保存、预览、次级提交 | 不得与危险操作同色 |
| Ghost | 工具栏、轻操作 | 必须有悬停与焦点态 |
| Danger | 删除、封禁、退款、放行 | 必须二次确认并显示影响 |

按钮状态：默认、hover、focus-visible、active、loading、disabled。loading 时保留原宽度；disabled 必须说明原因。

### 表单

- 标签常驻，不能只用 placeholder 作为字段名。
- 必填项显示“必填”和业务原因；错误显示在字段下方并关联 `aria-describedby`。
- 保存分“保存草稿”和“提交/生效”；高风险配置不能自动生效。
- 长表单分组并提供顶部错误摘要；离开未保存页面时提示。
- 金额、算力、时长、比例和日期使用明确单位，输入与显示采用同一舍入规则。

### 表格

- 服务端分页；默认稳定排序必须包含唯一键。
- 支持列显隐、筛选、排序和在权限允许时导出。
- 批量操作显示选中数量、影响范围和不可操作原因。
- 固定首列和操作列时必须避免遮挡；空数据、无匹配数据和无权限是三种不同状态。
- 财务、审计和合规表格显示数据快照时间。

### 弹窗与抽屉

- 确认弹窗只处理一个决策；复杂编辑使用抽屉或独立页面。
- Escape 关闭非强制弹窗；危险确认正在提交时禁止重复关闭和提交。
- 关闭后焦点返回触发控件。

## 5. 业务组件

### 项目与剧集状态

- 使用状态标签 + 当前阶段 + 阻塞原因。
- 阶段推进显示前置条件；不得仅显示“不可操作”。
- 已归档项目默认只读；恢复编辑必须产生审计记录。

### 资产卡片

- 展示资产类型、名称、主参考、版本、授权状态、引用镜头数和风险标识。
- 选中、主版本和候选版本使用不同语义，不能都依赖描边颜色。
- 替换资产前展示受影响的项目、剧集和镜头数量。

### 分镜表与故事板

- 镜头 ID 永久可见；镜号/顺序可变。
- 行/卡片显示角色、场景、台词、时长、生成状态、成本和问题数。
- 拖拽重排支持键盘替代操作；批量编辑提交一次版本变更。
- 虚拟列表必须保持选中、编辑和滚动锚点稳定。

### 生成任务

- 状态统一显示 pending、queued、running、success、failed、retrying、cancelled、timeout。
- 展示模型、进度、排队、预估/实际算力、开始时间、失败原因和恢复动作。
- 批量任务显示总数、成功、运行、失败和取消数量；部分失败不能显示整体成功。
- 取消按钮必须说明供应商已开始执行时可能产生的实际费用。

### 媒体预览

- 图片支持缩放、适应、原始尺寸、前后对比和引用信息。
- 视频支持逐帧/逐秒定位、播放速度、音量、字幕、水印、版本和时间点批注。
- 媒体加载失败显示原因、重试和原始文件信息；签名 URL 不写入日志或 DOM 长期缓存。

### 时间线

- 视频、配音、字幕、BGM、音效和审片标记分轨显示。
- 所有时间使用毫秒整数；帧显示由项目帧率换算。
- 拖动、裁剪和替换产生可撤销编辑命令；保存时生成版本。

### 合规门禁

- 风险项显示规则版本、证据、级别、责任人、状态和解除条件。
- 阻断项使用危险样式且不可被普通用户隐藏。
- 正式导出按钮在阻断时显示“解决风险”入口，不允许仅通过前端解除禁用。

## 6. 页面状态

每页至少实现：

1. 初始加载：结构化骨架屏，不使用全屏旋转器遮挡上下文。
2. 空数据：解释原因、适用条件和有权限的下一步。
3. 加载更多：保留已加载内容和滚动位置。
4. 后台处理中：允许离页，通过任务中心和通知继续追踪。
5. 成功：显示结果摘要和下一步，禁止只用短暂 Toast。
6. 可恢复失败：说明原因、保留用户输入、提供重试。
7. 不可恢复失败：提供请求 ID、工单或管理员入口。
8. 权限不足：不展示敏感数据，说明所需角色或申请方式。
9. 版本冲突：展示当前版本与用户修改，支持刷新或另存版本。

## 7. 交互反馈

- 普通点击反馈 100–150ms；面板 180–240ms；页面切换 200–300ms。
- 尊重 `prefers-reduced-motion`，关闭非必要位移和循环动效。
- Toast 用于可撤销或非关键反馈；计费、导出、审核等结果必须在页面保留记录。
- 自动保存 800–1500ms 防抖；显示保存中、已保存、离线和冲突状态。

## 8. 可访问性与键盘

- 所有可操作元素可通过 Tab 到达，焦点顺序与视觉顺序一致。
- 使用 `focus-visible` 高对比焦点环；禁止全局移除 outline。
- 表格、树、Tab、菜单、对话框使用正确语义和 ARIA 属性。
- 快捷键不得覆盖浏览器和输入法常用组合；提供快捷键帮助。
- 图片和视频结果提供业务性替代文本；装饰图标设置为不可访问。

## 9. 前端实现边界

- 页面组件不得自行推断权限、计费或合规结论，只消费服务端返回的能力和状态。
- API 状态使用统一查询缓存；任务进度通过 SSE 更新后仍以详情查询校正。
- URL 保存可分享的筛选和对象上下文；临时选中和未保存编辑留在页面状态。
- 服务端错误码映射到统一错误组件，禁止逐页拼接不一致文案。
- 生产环境禁止展示原型中的“已补齐”“可模拟”“应用到当前项目”等原型说明文字。
