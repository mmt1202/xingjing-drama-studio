## 实现与数据来源

- `server/xingjing_projects_runtime/control.py` 增加 `GET /api/v1/projects/{projectId}/control`。项目、生产账本、冻结剧本与资产、分镜、时间线/成片、生成任务/费用、客户确认和合规交付记录按可信工作区聚合，统计不写回项目定义。
- 剧集列表支持搜索、状态组合过滤、稳定播放顺序和服务端分页；任务、生成费用、阶段记录支持全部 / 7 天 / 30 天。剧集始终展示当前版本状态。
- 发布包只统计当前绑定成片版本的记录，不表示已经外部发布；完成项目还要求各计划剧集的目标平台发布包、客户确认和合规记录满足门禁。缺记录与零费用分别显示，各币种单列。
- `control_actions.py` 使用现有 actions 端点处理 `advance` / `rollback` / `updateOverview`。阶段转换由服务端状态机计算，不能任意指定目标状态；需要相应产物、模块权限和操作原因。参考视频路线可跳过分镜阶段。
- 配置允许编辑名称、负责人、目标平台、计划预算、工期和制作/审片席位。负责人变更校验同工作区有效成员；内容类型与生成路线不在允许字段内；已完成项目不能改变目标平台。
- 写入使用 `If-Match` 版本、`Idempotency-Key`、操作者摘要和持久化审计回执；同键同内容重放原结果，同键不同内容或旧版本冲突返回 409。审计和 outbox 与 SQL 变更同事务。
- 项目配置以 SQL 为真相源，提交后同步生产目录投影。投影失败返回可重试错误；同键重试按最新 SQL 修复投影，不重复增版本，也不会被旧回执覆盖新配置。
- `ProjectControlPage` / `ProjectOverviewSettings` 提供总控及配置面板；`ProjectFlowShell` 在正式项目路由提供 13 个阶段入口、工作区/项目/剧集/对象上下文、前置条件说明和恢复入口。分集页面及剪辑入口消费选定剧集和时间线。
- 导出入口携带当前剧集绑定的成片版本；切换剧集会清除前一集的时间线/成片对象。返回总控恢复筛选分页，未保存编辑和执行中的操作阻止通过共享导航离开。新文本具备 zh/en/vi 翻译。
