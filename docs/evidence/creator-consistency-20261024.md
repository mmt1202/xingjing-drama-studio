# 创作者公共布局与项目卡片一致性（2026-10-24）

用户反馈首页与项目库像两套产品。本轮按新要求统一为固定文字导航，取代首页独立的图标窄栏；冻结原型资料保持不变。

## 实现

- 创作者首页、工作区页面与项目内公共壳共用 264px 文字导航、星镜“星”字徽记、69px 顶栏、背景及紫橙主按钮；移动端保留菜单入口。
- 项目库不再套整页玻璃大卡，不影响其他剧本/业务页面的已有容器。
- 首页和项目库使用同一个 `ProjectCard` 展示组件：相同表面、圆角、状态、类型/平台、名称、项目 ID/版本、更新时间与轻量入口；归档/恢复保留为项目库管理操作。
- 类型、平台与状态复用三语映射。建项草稿与生产状态 `draft` 分开显示，后者在建项完成后保持真实语义；不将负责人 ID 当成人名。
- 读取、归档、恢复、续建和安全回跳保持原流程，创建/归档/恢复按现有管理权限显示，共享卡不拥有业务副作用。

## 验证

- 前端构建（含类型检查）和 ESLint 通过。全量检查为 1832 passed / 25 failed，与用户已批准的登录品牌提交相同：19 项引导旧品牌断言、4 项登录、2 项旧根路由；无新增失败。
- 使用正式 Java/Python/PostgreSQL 会话读取首页、项目库并进入项目总控。首页与项目库的计算样式一致：侧栏 264px、顶栏 69px、卡片背景 `rgb(17,20,29)`、圆角 14px、同一星镜图标及主按钮渐变，均无横向溢出。
- 首页填入临时未保存名称后切换项目库被阻止；清空后正常离开，没有提交草稿或改动业务数据。
- 新增项目库文案三语；未创建或修改测试文件、测试脚本、fixture 或 snapshot。
