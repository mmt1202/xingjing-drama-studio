日期：2026-10-23。证据 ID：EV-M18-VERSIONS-003。范围：CR-115 版本记录、原领域恢复及旧聚合入口范围修复。状态：本地实现与验证完成；真实服务联合验收保持开放。

## 原型与可用功能

依据原始 v9.2 `creator/version-history.html` 与逐页目标，将通用偏好 JSON 页面替换为项目内专用版本工作台。沿用创作者公共壳、四项真实指标、左侧版本历史与快照、右侧 360px 比较面板；不改冻结的 `docs/product/v9.2`。

- 从同一权威 SQL 来源读取剧本、资产、分镜、故事板与成片。类型、名称/ID、剧集、对象、当前/冻结/可恢复状态组合过滤，稳定排序和服务端分页。
- 同一对象任意两版字段比较，显示明确 ID、来源、父版本、完整源摘要与当前修订；JSON 对比报告由服务器重新鉴权、持久化并审计后下载。受控媒体路径和秘密不进入比较投影，隐藏字段单独变化仍由源摘要差异表达。
- 快照保存明确引用、源摘要、说明、操作者和时间，不增加源版本。恢复调用各领域实际写服务：剧本完整场景/段落/原文映射、资产不可变派生版本、镜头稳定身份/当前位置、故事板镜头顺序和引用校验。保留既有历史与下游冻结引用。
- 冻结只操作真实可冻结的当前剧本/故事板；冻结后遵循原领域限制。成片操作更新真实 `FinalVideoSelection`，不重新渲染，不替换已冻结发布材料。
- zh/en/vi、加载/空/权限/服务/并发状态、无效明确版本保护、返回筛选分页/滚动、导航保护、账号/项目隔离的操作草稿和稳定重试键。

镜头节点是原故事板版本内该镜头的真实冻结内容，沿用故事板版本号；未修改镜头的故事板修订可能具有相同镜头摘要，不等同于独立镜头历史表。剧本冻结只推进对象修订并锁定已有内容版本，不增加源版本总数。

`versionNumber` 为来源业务号，成片使用关联冻结时间线的 revision，精确身份由 `versionId` 表达；成片的 `headRevision` 是选用记录修订。缺失历史时间/操作者保留未知，今日新增仅包含可核验 UTC 时间。没有持久冲突事实源时显示“—”。扫描最多 5000 个节点、单内容 2MiB、聚合内容 32MiB、差异 2000 项；超过上限明确 422，不截断后宣称完整。

## 接口、权限与持久性

前缀 `/api/v1/projects/{projectId}/version-history`，响应 `{data,meta:{requestId}}`。

| 方法/路径 | 用途 |
|---|---|
| GET 根路径 | 授权范围内版本、统计、筛选/分页及能力 |
| GET `/detail` | 精确 Ref 的节点、同对象历史及脱敏内容 |
| GET `/compare` | 明确两版差异与源摘要 |
| GET `/checkpoints` | 当前授权下的不可变快照分页 |
| POST `/actions` | snapshot / lock / restore，版本 CAS、完整摘要、说明与幂等键 |
| POST `/reports` | 持久比较报告、审计与稳定幂等结果 |

项目入口要求 `project.view`，数据再按 `script.view / asset.view / shot.view / final.view` 分别裁剪。快照要求 `project.manage` 和来源读取权限；恢复/冻结要求来源业务 `.manage`。可信身份、租户、工作区、项目未删除、当前项目分配和工作区权限交集都在服务端校验；API Key、窄/混合/未知范围拒绝。资产全历史仅允许所属项目读取；完成回执重放仍检查当前权限。

原 `/api/v1/account/version-history` 保留旧响应形状和 `settings.view` 兼容条件，另复用同一项目授权及逐域读取规则，设置权限自身不能读取生产数据。旧 `timeline` 仅作为 `final.view` 下同源、有限量的只读投影保留，未加入统一 Ref/写动作。

新增迁移 `a9d4d7deeee9`（父 `98c3c6cfddd8`），四表保存 checkpoint、command、report 与 audit，审计及 outbox 与统一结果同事务。领域写入可能跨越独立事务，持久 pending claim 与原领域稳定回执负责恢复已提交结果；原应用修订通过 `appliedRevision` 返回，节点保持读到的真实当前修订/状态。同步 SQL/领域写入移入工作线程。

`XINGJING_VERSION_DATABASE_URL` 必须是同步 SQLAlchemy URL，并与配置的 project/content/asset/storyboard/editing 等权威来源同一物理库；自定义成员还检查团队来源。缺配置、缺表或不同库返回 503，不在运行时建空表。应用装配同步/异步同源 Session 并关闭资源。

**默认应用尚未注入生产 QualityPolicy，因此故事板冻结不可用。** 该操作需要在应用组合处传入可信生产策略；没有可用的环境变量开关，不能自造质量阈值。故事板读取、比较、快照和历史恢复不因此伪造冻结结果。
