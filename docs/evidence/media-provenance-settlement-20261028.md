# 素材来源、生成恢复与成片结算修复

日期：2026-10-28。范围：主体资产首图、固定输入媒体、生成工作台恢复、跨集导航和成片结算。此记录不代表整个制作平台已完成验收。

## 根因与交付行为

- 主体资产只有派生图入口，没有第一张参考图入口。新增从保存描述生成参考图、预览和采用；采用形成新版本，旧描述版本保持原值。三视图、表情必须使用已采用图片；音色不走图片参考流程。生成与采用在资产所属项目执行，共享项目保留权限内的精确引用读取。
- 分镜执行曾将固定资产版本降成资产 ID。现在显式传递版本和目录 JSON 摘要，服务端解析成不可变生成媒体；分别核验 JSON 摘要、文件二进制摘要、大小、归属及来源任务，实际字节进入网关。客户端不能注入服务端已解析字段。
- 参考媒体网关要求 `verified-media/v1`，部署方尚未确认时在计费前拒绝。首尾帧数量和顺序、图片/视频类型受控；未接通原图与遮罩角色的局部重绘继续禁用。环境开关默认关闭，真实配置未自动开启。
- 生成表单以真实素材及版本选择替代手填 ID。模型目录、输入协议和配置状态决定能否提交；高级参数保留为可选项。
- 未知提交结果保留原参数和请求编号；会话内持久化成功后才发送。刷新后仅恢复界面，不自动生成；用户手动恢复同一请求。成功创建与列表刷新分别处理，刷新失败不会被当作创建失败。任务列表刷新/筛选保持表单，详情迟到响应不能覆盖新选择或重新打开已关闭详情。
- 服务端先读取同键既有任务，再检查新任务所需的供应商和计费配置；通道暂时缺失时仍能恢复已接收的回执，新请求继续明确拒绝。
- 主体资产的首图、三视图、表情与采用也保留原动作、完整参数、所属项目、CAS 和请求编号。即使刷新后资产已有新版本，恢复仍回放原命令；先持久化已知任务回执，再清未知请求。明确拒绝可释放恢复状态，浏览器存储不可用时阻止外发。API 幂等指纹区分不同 CAS。
- 素材客户端和默认生成客户端按当前登录边界创建，避免登录前导入模块导致登录后读取失败；跨登录数据和草稿保持隔离。
- 跨集导航补齐目标集的真实生产引用，明确指定的历史文档、快照和时间线保持原选择。负责人展示姓名，保存仍使用成员 ID。
- 资产详情、三视图和表情深链按 ID 独立读取，列表第一页、筛选和分页不影响详情存在性；工作区/项目边界和迟到请求受控，后台重读保留编辑器。第 61 项资产及历史主版本已验证，不猜最新版本。
- 导出原先核对项目内全部任务，其他集任务可能误拦当前成片。现在从固定成片、渲染和时间线逐项追踪实际媒体，递归 M06/M07/M08 来源，按相关任务验证结算。成功输出仅释放预留不算已结算；缺失来源、循环和摘要不一致明确拒绝。
- 新精确范围凭证写入独立表，记录被取代的旧凭证；旧结算行和已完成导出回执保持原值。封面按固定选用版本单独核验，不改变成片自身的成本摘要。

## 限制与下一步

供应商接收端不在本仓库；MockTransport 收到正确字节不证明真实供应商使用了这些媒体。开发仍需提供或接通实际供应商适配器/网关接收实现，部署方提供凭据和环境配置；完成协议联验后才开启参考素材生成，再以获准的独立项目完成真实第一集联合验收。缺少接收实现不是仅配置 API Key 能解决的操作项。

会话存储恢复不承诺跨浏览器或关闭浏览器会话后的恢复。未知任务不会因等待时间长自动创建新任务。局部重绘、原子预算限制、长文本语义映射/局部恢复、真实商户和实际发布仍在完整验收清单中。

本轮未创建或修改测试、测试脚本、夹具或快照；未调用付费供应商或修改实际项目的制作内容。完整范围见 [产品验收状态](../project/product-acceptance-status.md)。
