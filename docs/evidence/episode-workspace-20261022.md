日期：2026-10-22。改动基线：`29073989`。本记录覆盖分集规划与管理主流程；需求保持「开发中」，未完成 A1 联合验收。

## 已实现

- 项目总控增加分集编辑器与剧集管理入口。页面沿用原型的暗色工作区、橙色主要操作、剧集表格及单集详情；新增文本有 zh/en/vi 三语。
- 按段落拆分所选源文件尚未分配的尾部文本，先预览再应用，不调用付费模型。保存后写入生产账本与 `source/episode_N.txt`，采用既有 Unicode NFC / 换行归一化坐标。
- 新增分集、修改标题、集尾钩子、故事节点、下集预告、单集目标时长和人民币预算；支持复制末集结构。复制不继承原文范围或生成素材。
- 自动保存、手动保存、保存状态、冲突保留编辑稿、下载编辑稿、确认后重新读取。原文范围越界、重叠、源文指纹变化、重复集号、已制作分集标题/原文改写均在服务端拒绝。
- 拖拽与上下移按钮调整播放顺序；集号及剧本、媒体文件身份不变。ProjectManager 读写和剧本同步保留 `episode_order`，下集大纲跟随播放顺序。
- 单集目标时长进入分镜路线和参考路线的剧本规划提示；属于规划目标，不保证实际成片精确到秒。预算保存为计划，不作为扣费或硬限制。
- 剧集管理支持搜索、状态过滤、分页、选择、批量准备度检查及继续到剧本、分镜、发布包工作台。准备度检查覆盖钩子、原文与剧本，不代替内容/版权审核。
- 制作状态及分镜/视频完成度由既有 StatusCalculator 读取生产数据计算；费用通过既有 CostEstimationService 读取当前模型估算与已记账费用，按币种分别展示。无法取得价格或记账数据时不填入虚构数字。

## 接口与数据约束

- `GET /api/v1/projects/{id}/episodes`：可信工作区内项目的账本、原文、读时状态、版本摘要；支持 `q`、`productionStatus`、`offset`、`limit`。
- `POST /api/v1/projects/{id}/episodes/split-preview`：携带 `If-Match`，只生成预览，不写入。
- `PUT /api/v1/projects/{id}/episodes`：携带 `If-Match` 与 `Idempotency-Key`。摘要涵盖账本、原文及制作锁定状态，过期请求返回 409。
- `GET /api/v1/projects/{id}/episodes/costs`：可信作用域内的实际计价服务读取。
- 读取要求 `project.view`，编辑/预览要求 `project.manage`；归档项目隐藏，建项草稿拒绝操作。客户端作用域请求头不能覆盖可信会话。
- 文件操作复用生产文件锁顺序，写入派生原文后原子提交账本；普通写入异常恢复备份。文件账本保留有界命令回执，SQL 持久化 inbox、audit、outbox。SQL 提交失败后同键重试可恢复审计，不重复修改分集。文件回执淘汰后，SQL 中已使用的幂等键仍拒绝再次写入。
- SQLite 在 inbox savepoint 前先启动实际写事务，避免审计回滚后 inbox 独立提交。SQL 项目行保护同时覆盖归档并发。没有新增迁移或第二套分集真相源。
