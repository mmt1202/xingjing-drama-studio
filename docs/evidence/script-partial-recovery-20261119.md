# 剧本局部恢复验收记录

2026-11-19，CR-095。入口为项目内的「剧本版本对比」。只有一版时，编剧可直接打开正文编辑器保存下一版。冻结剧本和只读成员看到当前正文的查看入口。

## 编剧如何使用

选择历史版本，指定要恢复的整场、场景标题、对白、旁白或动作。在当前稿中明确选择替换目标、插入位置或移除对象。一次可以选取多项。填写原因后，预览逐项显示当前内容、恢复后的内容以及合并后的全文。

可编辑剧本会追加一个版本。冻结剧本会生成独立的 v1 工作副本，并记录父稿、冻结版本和取材版本。原稿属于某一集时，预览会说明哪一集将得到新的工作稿、它将接替哪一份工作稿。确认分集副本需要项目和剧本管理权限。

## 制作引用与并发

- 场景及段落编号按版本内顺序生成。恢复使用用户明确选择的两个版本和对象，将已确认的来源带到新的编号。场景内容或段落的场景语境发生变化时，对应映射需重新核对。原样复制的段落保留原文范围、确认人和时间。
- 预览列出可见的导演方案、分镜和素材引用数。不同数据库或权限范围之外的引用数显示为不可查看。工作稿的结构统计随正文重算，旧稿的 AI 分析可从版本历史查看。
- 保存会重新检查权限、剧本版本、制作引用和当前分集工作稿。版本和影响一致才提交。回执、版本、必要的分集关联和内容审计在同一数据库事务写入。
- 当前浏览器会话保存选取的对象、恢复原因和待核对请求。提交后断网可以核对原请求。重新打开页面只读取服务端状态。
