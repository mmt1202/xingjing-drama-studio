# 创作者公共布局对齐记录

日期：2026-10-23。范围为创作者工作区与项目流程的公共布局；按用户“整体都不像，先统一公共布局”的反馈，暂停新增下一项业务功能。

## 对照依据与原因

直接在浏览器打开原始 `D:/aivideo/xingjing_web_full_v9_2_nav_fix/creator/home.html`、`project-overview.html`、`data-dashboard.html`，保存原型、修改前和修改后截图。原型首页使用 72px 图标导航，项目与看板使用 264px 文字导航；不能把另一组未应用于这些 DOM 的 282px 样式当作依据。

原实现的三个确定偏差：默认入口与登录缺省返回仍进入旧 `/app/projects`；工作区统一使用不对应原型的 208px 侧栏；项目流程完全没有全局侧栏，并将项目身份与阶段条压在同一顶部区域。

## 实现范围

- 抽出纯展示 `CreatorShell` 与局部 `--xj-*` tokens，统一品牌、导航、顶栏、背景、字体、控件尺寸、边距与焦点状态。首页 compact 72px，工作区及项目 expanded 264px；项目顶栏实测 69px。
- 工作区继续保留可信 context、原有导航 guard、首页/看板查询与 document 滚动恢复。新增顶栏搜索使用真实首页项目筛选，不展示未接入的全站搜索。
- 项目继续独立读取真实 control 数据、阶段、剧集、前置门禁与版本参数；单独并行读取工作区 context 决定公共入口权限，不使用项目权限替代工作区权限。工作区 context 故障只禁用公共入口并允许重试，不卸载可读项目。
- 项目拆成公共顶栏、项目身份卡、胶囊阶段导航和正文玻璃面板；总控移除重复项目名称与元数据，保留刷新、配置、剧集和生产操作。
- 新建/继续建项向导接入同一工作区壳，新增公共出口经过未保存保护；已有草稿清空名称仍受保护，已就绪只读项目可正常离开，明确“放弃更改并返回项目库”作为退出操作。
- `/`、`/app` 与登录缺少安全回跳时进入 `/app/home`，经可信 session 选择当前工作区。明确指定的旧大厅/Studio 深链仍可访问，安全 return 校验保留。
- 后台表格、按钮焦点与禁用态、减少动效的裸 CSS 选择器限制在后台容器内，避免污染创作者与旧 Studio。

公共壳保持 document 主滚动，没有把首页/看板改为内部滚动容器；全局侧栏只有一个，z-index 20，不覆盖原 modal/toast。旧 Studio 的资产栏、助手、SSE 和任务生命周期没有迁移到新壳。旧 onboarding 不覆盖新工作区路由。
