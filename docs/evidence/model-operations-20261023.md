## 实现与契约

- `frontend/src/xingjing_model_operations/` 提供暗色模型卡片、四项真实统计、组合筛选/分页、右侧详情与业务表单。所有新增文本提供 zh/en/vi。
- 目录是平台共用配置；策略、审计和本月调用证据按可信租户/工作区隔离。每个请求校验 `admin.model.view/manage`，运营入口拒绝 API Key，预期工作区不一致返回 404。
- 接入/编辑支持模型身份、名称、版本、区域、媒体/能力、并发、凭据引用以及参数类型/枚举。已注册供应商身份保持稳定，新模型默认下线。凭据只接受 `env://` / `secret://` 引用；响应、命令回执与审计不返回引用值。
- 上下线提交明确目标状态及原因。上线要求有效价格和凭据引用；配置引用不证明连接通过。旧后台通用切换入口返回 409，避免绕过新校验。
- 价格版本不可重用，金额为正整数最小货币单位，币种三位大写。发布即生效，旧报价停止生效但保留历史；已接受任务沿用冻结报价。
- 工作区策略支持能力/媒体、允许模型、主模型顺序、优先或权重选择、备用开关、币种/成本和延迟/连续失败/成功率阈值。主模型权重为正整数且合计 100%。
- 路由选择最新有效报价，结合能力、参数类型/枚举、凭据、上线、并发及实际健康执行策略。失败门槛最多为既有全局 3 次；成功率使用当前工作区最近 20 条终态调用证据，至少 5 条才应用阈值。
- 生成端 `GET /api/v1/generation-models`、项目默认模型与提交路由读取同一数据库；生产组合不再以环境 JSON 目录为真相源。`XINGJING_MODEL_DATABASE_URL` 可与生成库分开配置，关闭时释放两个引擎；未配置时沿用生成库。
- 命令使用对象版本和稳定幂等键；相同请求重放原回执，冲突返回 409。修改、回执、脱敏审计与现有 outbox 同事务提交。审计可按请求 ID、操作者、对象或原因、时间及分页查询。
- 前端取消过期读取、失败保留编辑、同正文重试复用幂等键，409 后显式放弃/重读；内部导航和刷新保护未保存表单。

- 优先、权重、备用、最新价格、币种/代价、能力/参数、延迟/失败/成功率及最小样本限制。
- 模型下线后，已接受任务仍可释放调用槽位；回执、审计和 outbox 数量一致，注入 outbox 故障后修改及审计整体回滚。

`output/model-operations-live-catalog-20261023.log` 另记录 **19 项断言通过**：

- 使用不同模型/生成数据库建立生产组合，项目读取仍在生成库，默认模型正确来自模型库。
- 已下线、无有效价格或无凭据引用的模型不进入生成目录；无真实适配器/计费部署不虚构可用性。
- 数据库报价覆盖旧环境报价，发布新价格后立即回读同版本，实际路由选择与展示一致。
- 下线即时移除目录、提交可用状态及旧报价，项目默认模型被拒绝；关闭释放两库连接池。
- 缺少迁移时，目录/详情/审计均返回 503，生成目录错误归一为不可用；引用值不泄露。

81 为两组断言总数，不等同于 81 个独立端到端用例；没有提交付费生成任务或证明真实供应商/计费回调通过。
