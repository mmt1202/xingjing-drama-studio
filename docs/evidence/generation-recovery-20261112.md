# 异常生成任务核验与恢复记录

日期：2026-11-12。承接 [模型额度恢复](model-capacity-recovery-20261112.md)；本记录证明专用核验应用与隔离验证范围，不代表真实供应商故障或首集成片已完成验收。

## 交付行为

- 管理员在当前工作区的任务核验页查看待关注/已处理/全部任务、原制作请求、固定素材版本、供应商执行信息、占用费用、回执和历史记录。权限要求业务与财务查看；预览及执行另需两项管理权限。
- 部署适配器通过独立 HMAC 域提交不可变回执。任务、执行身份、请求摘要、调用次数、币种和价格版本必须匹配；成功结果验证实际文件字节、媒体类型和产物摘要。
- 管理员先预览原占用、实际收费和释放额，再填写原因并确认。预览绑定状态、操作者和回执，10 分钟有效；相反证据、过期、状态或文件变化会阻止执行。
- 在原任务上恢复产物或确认失败，任务、产物、结算、证据、处理结果和审计同事务。执行不调用模型；原生认领失效，终态模型名额幂等释放。并发处理、普通回调与处理竞争、换键重试均不能重复结算。
- 写响应丢失时保留会话范围内的原请求，重开不自动提交；显式重发使用原键和原内容。读取失败保留处理说明，阻止使用失效详情执行；切换筛选失败不展示上一组任务。
- 旧后台“执行补偿”不再向严格任务快照写入自定义字段。历史任务缺少身份但仍持有费用时进入待关注，明确阻止猜测性退款。

页面路径：`/app/workspaces/{workspaceId}/admin/admin-tasks`。协议、费用及适配器证据要求见 [接入约定](../project/generation-recovery-integration.md)。新增页面和错误文案具有 zh/en/vi 三语。
