# 制作流程交接与版本一致性修复

本次检查覆盖分集、剧本、资产、分镜、生成、音频字幕、剪辑、审片与导出之间的真实数据交接。冻结需求 `docs/product/v9.2` 保持不变；页面存在不代表外部生产验收完成。

## 根因与修复范围

| 断点 | 修复后的约束 |
|---|---|
| SQL 导入原文与文件分集来源分离，分完没有各集 SQL 工作剧本 | 来源目录明确列出原文身份、摘要和 NFC/LF 字符坐标；按需读取正文。对已保存范围显式创建独立工作稿，同范围幂等复用，改范围需明确创建新候选并保留历史稿。 |
| 分集选择只存在页面状态，下游可能仍指向上一集 | URL、全局生产上下文和模块跳转携带当前集、工作稿、冻结剧本及资产快照；过期或冲突引用不静默替换。 |
| 全部导入文档被当作必须完成的生产剧本 | 阶段证据按各集采用的工作稿／冻结绑定计算；未使用的原文不阻塞进度。缺集、来源不匹配、无效绑定不能算全项目就绪。 |
| 冻结分镜先提交生成任务，随后因为不可修改而拒绝记录 | 冻结计划与执行记录分离；计划内容仍不可变，任务提交与采用媒体保留作用域、版本和可恢复请求身份。 |
| 音频类型与字幕载荷结构在 M07/M08 不一致 | 对白、旁白、混音可进入对应音频轨道，字幕按实际 `{durationMs, cues}` 合同读取，同时兼容旧数组。 |
| 轨道升级后旧时间线找不到历史版本 | 精确版本读取不再要求等于轨道当前版本；素材选择列表继续展示当前版本。 |
| 已完成对口型产物没有剪辑素材入口 | 已选择且真实就绪的输出进入素材目录；历史精确引用不随取消选择而消失。范围、文件摘要、大小和实际时长都经过校验，无输出的回退记录不冒充对口型成片。 |
| 不同媒体类型各自分页导致合并列表超过页长、跨页跳项 | 按统一排序合并候选后应用页长与偏移。包含损坏／不可用媒体时的分页补齐仍需继续优化。 |
| 资产保存失败卸载编辑器、分镜子页只切本地状态 | 保存错误保留编辑草稿并阻止误离开；分镜子页使用可刷新恢复的实际路由。 |

## 保留边界与后续优先项

- 创建分集工作稿不等于 AI 改编成功，也不等于剧本已冻结；普通小说片段仍须改编、校验并明确绑定。长篇分集目前是确定性切分，未实现完整语义分章和长文本自动编排。
- 冻结分镜的镜头记录保留了资产版本，但 M06 的供应商请求目前仅传资产 ID，尚无可验证的精确资产版本输入合同；不能据此宣称外部适配器一定使用了冻结的版本。此项需要补齐请求、解析器及实际供应商联合验收。
- 导演候选／人工确认的独立版本链、原文章节语义映射、局部回滚仍未完成。完整导演字段只构成当前配置证据，不冒充已实现独立确认流程。
- M09 当前按整个项目核对生成／音频／渲染费用结算。多集并行时，其他集未结算任务可能挡住某一集成片导出；应沿精确时间线的素材版本追溯相关任务，同时明确跨集共享素材的成本归属，不能简单忽略冻结费用。
- 进程在持久化 dispatch 标记之后、M06 创建任务之前崩溃，系统保持明确待核验状态，避免不确定重提产生重复费用；该窗口的自动恢复／安全自助取消仍需 M06 原子准入控制。普通响应丢失、确定拒绝和已存在任务的恢复已覆盖。
- 既有成功采纳回执仍在当前任务与文件检查之后读取：镜头已经换任务或原文件不可用后，旧键可能不能回放成功结果；不产生重复收费，但需后续把已完成回执的授权回放与新写入验证分开。
- 项目预算的原子硬限制、真实外部模型／音频／渲染供应商联合验收、实际发布回执仍是后续工作。
- 本轮不调用外部付费模型，不修改用户项目原文、剧集或生产绑定，也不把隔离验证生成的媒体放进正式项目。
