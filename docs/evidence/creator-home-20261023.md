## 实现与契约

- `frontend/src/xingjing_creator_home/` 提供独立首页和工作区外框，按原始 `creator/home.html` 使用暗色画布、故事输入主区域与固定 11 项一级入口。项目生产阶段保留在项目内。旧项目列表增加首页入口，工作区选择完成后可进入首页；旧默认路由保持兼容。
- `creator-context` 与既有 `session/context` 联合解析可信用户、工作区和服务端权限。URL 与会话不一致时不渲染业务内容，提供重试/切换工作区。
- 故事正文支持粘贴及 UTF-8 TXT / Markdown，最大 2 MB、100 万字符。四种制作起点保存为建项草稿，复用 `POST /api/v1/projects/{projectId}/actions` 的 `new` / `saveDraft`，然后进入该 ID 的引导配置；首页不发起生成或扣费。
- `GET /api/v1/workspaces/{workspaceId}/creator-home` 按可信租户与工作区读取非归档项目，支持名称/ID、日期、状态、类型组合筛选及服务端分页，以更新时间和 ID 稳定排序。只返回项目摘要，不返回完整配置、原文或预算。
- 最近列表的查询和滚动位置按用户及工作区保存在会话存储中；返回时等待内容布局恢复，并在用户主动操作时停止滚动修正。文本、偏好未保存或操作执行中有导航及刷新保护。
- `GET /api/v1/workspaces/{workspaceId}/generation-tasks` 关联实际 M06 任务和当前工作区项目，排除归档及建项草稿，不返回任务快照、提示词或供应商秘密；支持搜索、状态、日期和分页。
- 工作区任务打开精确项目与 `taskId`，生成工作台按该 ID 读取详情。修复原有项目任务入口被转换为未映射生成能力路径的问题。
- 模板区域只读取当前账号可访问的实际市场记录；服务未配置时显示失败与重试。数据看板 CR-025 尚未开放，一级入口保留禁用原因。
- 首页偏好沿用 `GET/PUT /api/v1/account/preferences` 的 `creator-home` 资源，按账号/工作区隔离。区块显示、默认起点、默认时间及每页数量使用明确表单，保留已有扩展配置。
- 偏好严格校验已知字段，使用版本、稳定幂等键、行锁/唯一约束，更新、命令回执、审计和 outbox 同事务提交；重复请求返回原回执，并发旧版本返回 409。请求携带的预期工作区与可信会话不一致时返回 404，防止旧页面误写新工作区。
- 首页与项目读取使用 `workspace.view` / `project.view`，创建需 `project.manage`，任务还需 `generation.view`，模板需 `template.view`；偏好单独使用 `settings.view/manage`。新页面文本同时提供 zh/en/vi。
- 没有新增依赖、迁移或生产数据库写入。
