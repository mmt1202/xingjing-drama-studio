## 实现与业务约束

- `frontend/src/xingjing_internal_review/` 提供原型同屏布局：播放器、时间点表单和评论在左侧，回合与审批结论在右侧，复用项目阶段导航；新增文本 zh/en/vi 齐全。
- 从真实 `FinalVideoVersion` 及冻结 `TimelineVersion` 读取版本、剧集、时长、镜头片段；首次创建需显式选择版本。同集上一回合锁定后才能创建下一回合，不同集可并行。
- 批注绑定精确回合/成片、毫秒时间点及可选镜头；回复继承根问题的时间点/镜头并禁止嵌套回复。重复镜头在多个片段中出现时，按镜头 ID 和所处时间范围校验，选项合并避免重复键。
- 所有根问题解决后才可通过。打回说明必填；未锁定终态可继续收集。新增根问题或改变处理状态清除旧审批，回复不改变结论；锁定只接受已决定回合，之后只读。
- 内部入口验证可信 `review.view/manage`，拒绝 API Key 和不匹配的预期工作区；交接另需 `export.view`。租户/工作区/项目范围由服务端解析。
- 项目行锁串行化编号、回合版本和命令；命令回执按租户/工作区/操作者/幂等键隔离，并检查完整正文摘要。相同请求重放原结果，旧版本或已锁定写入返回 409。
- 回合/批注、回执、既有 `ReviewAuditRow` 与平台 outbox 同事务。状态审计保留旧/新问题快照，不能只依赖回合问题计数推断旧状态。
- 审片媒体校验安全路径、文件大小、SHA256 和时长。短期票据不含 Bearer，绑定租户/工作区/项目/回合/成片/记录版本及签发操作者；取流检查项目未删除、版本仍有效及文件完整性。
- **媒体撤权边界：** 票据有效 120 秒，属于已经授予的短期读取能力；媒体 GET 不重新查询员工会话。业务请求权限撤销在下一请求生效，旧媒体票据到期或回合版本改变后失效，不能把它记作即时媒体撤权。
- 列表按名称/ID/成片/说明/结论、状态、剧集及成片筛选并服务端分页；选定成片筛选只约束回合，版本选项仍保留该集全部成片，方便创建下一轮。
- 前端取消过期读取，保留未保存草稿，导航和刷新保护编辑。409 保留输入、阻止旧版本继续写，并提供显式放弃/重读。同回合重读保持其他表单草稿及当前播放位置；仅实际请求处理中显示保存状态。
- 内部通过且锁定才可调用受控交接。返回精确成片、时间线、剧集及可信数据库发布目标，避免发布包选择器默认改选最新未审版。交接不创建发布包，不替代合规、正式导出或客户签收。
- 客户外链入口携带并预填当前成片版本，CR-011 / TM 外链管理和公共客户审片协议保持原有语义。

## 接口与迁移

- `GET/POST /api/v1/projects/{projectId}/internal-reviews`：列表与创建回合。
- `GET .../{roundId}`：成片、回合、批注、权限和短期媒体地址。
- `POST .../{roundId}/comments`、`POST .../{roundId}/comments/{commentId}/status`：根批注/回复与合法状态转换。
- `POST .../{roundId}/decision`、`/reopen`、`/lock`：通过/打回、继续收集、显式锁定。
- `POST .../{roundId}/handoff`：已通过且锁定版本的受控交接。
- `GET /api/v1/internal-review-media/{roundId}?ticket=...`：受控媒体，支持原生播放读取。
- 新迁移 `14332a65527a`，父版本 `a3c955c19e21`；增加内部回合、批注和命令回执表，复用现有审计/outbox。临时 SQLite 首次/重复升级与降级、PostgreSQL DDL 编译通过；未连接真实 PostgreSQL 或修改生产数据库。
