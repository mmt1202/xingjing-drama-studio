## 实现与契约

- 快捷创建集中填写，引导创建分为项目底稿、制作规格、预算审片三步。字段包含负责人、内容起点、类型、集数/时长、交付平台/画幅、风格、模型、语言、预算/排期、席位/轮次、客户权限及版权声明，支持 zh/en/vi。
- `GET /api/v1/project-setup/options` 返回当前工作区有效成员与已启用模型；`GET /api/v1/projects/{id}` 返回完整建项配置。
- `POST /api/v1/projects/{id}/actions` 支持 `create`、`saveDraft`、`activate`。新草稿使用 `id=new`，已有草稿必须携带 `If-Match`，写入必须携带 `Idempotency-Key`。重复请求返回原项目，内容变化的同键请求及过期版本拒绝；已激活项目不能重新改写建项配置。
- 数据迁移 `7d174f942017` 添加配置、草稿状态及重试摘要，既有项目默认 `ready`。草稿不创建生产目录，激活才创建原有 ProjectManager 项目、生成路线、画幅、计划集数/时长和交付目录。
- 部署模板补齐 `XINGJING_PROJECT_DATABASE_URL`，与内容、团队和模型使用同一个已迁移数据库。升级服务前执行既有 `uv run alembic upgrade head`；本次未修改或迁移生产数据库。
- 导入正文与项目激活在同一数据库事务保存为 M03 原文及第一版剧本，导演风格进入 DirectorProfile；正文同时投影到 `source/source.txt`。
- 品牌短片使用 `ad` 内容模式与单集目标时长；其余新建类型使用 `drama`。计划集数不伪装成已生成剧集。
- M06 未明确选择模型时读取项目图片/视频模型默认值，并继续经过工作区模型路由许可；停用模型拒绝使用，草稿拒绝生成。
- M12 新建外链表单读取项目客户权限默认值，仍允许创建者明确调整。读取失败阻止提交并提供重试；切换项目取消旧读取。
