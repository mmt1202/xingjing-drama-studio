## 实现与统计口径

`frontend/src/xingjing_analytics/` 对照原型提供四项指标、近六个月产出、模型分布、成员贡献、项目状态、成功任务趋势、费用和统计明细。工作区一级导航接通 `/app/workspaces/{workspaceId}/analytics`，新增文本 zh/en/vi 齐全，未知归属桶翻译显示而保留原始 ID。

`server/xingjing_analytics/` 复用 ProjectsRuntime 的正式异步数据库会话，查询现有项目、M06 生成、M07 音频、M08 渲染与冻结成片、M09 发布包及结算记录。GET 不写统计快照，不使用原型演示数字，不把当前实现记作完整 AnalyticsEvent/MetricSnapshot 事件仓库。

- 时间范围为 UTC 自然周、月、季度或全部，事件采用半开区间；本期截至读取时刻，上期是上一个完整自然周期，界面说明二者长短可能不同。
- 项目数为当前权限与对象筛选范围内的可见存量，不伪造历史项目数变化。只切分组维度不改变当前项目存量。
- 产出为窗口内有成片的 `(项目, 剧集)` 去重数；同集重渲染不在同一窗口重复计集。各日/月桶独立去重，同集跨桶重渲染可在多个桶出现，因此桶数不保证加总等于全周期去重数，也不表示首次完结集数。
- 镜头取该成片精确冻结时间线的视频轨镜头，按项目/剧集/镜头去重，不计规划或未成片镜头。
- 任务按创建时间归入窗口，状态为当前读取结果；成功率为成功 /（成功 + 失败 + 超时），取消和处理中单列，无终态样本返回 null。任务数不等于供应商 API 调用次数。
- 平均耗时只采用有明确成功完成时间的任务，界面同时显示样本数；技术再次尝试或重试任务单列，不冒充完整制作周期或内容返工。
- 模型按供应商与型号组合区分，音频缺具体型号时单列服务商来源；成员从原始提交证据读取，缺失归入未归属。回调系统身份不当作原提交人。成片与发布包无模型/成员因果字段，指定模型/成员时不计入其产出。
- 实际费用只汇总三个来源的 settle 流水，以结算入账时间归属；当前冻结取剩余 hold，不能再把 hold.actual_minor 叠加到流水。失败/重试金额是实际总额子集，不应再次相加。
- 金额按币种分开，后端整数求和并以十进制字符串传输；日均使用 Decimal，按已跨 UTC 自然日（含今日）计算到 0.01 最小币单位。全部范围无明确起点时不计算日均。前端使用 BigInt/字符串展示，图形仅转换有界比例，不以 Number 累计金额。
- 上期为零或无样本时不计算百分比；已授权账单范围内上期有币种、本期零消耗时显示零值和 −100%，不会把缺权限补成零。
- 正式发布包记录不等于外部平台已发布；无外部回执、完整制作起止或在线心跳时明确不可观测。

## 权限、部署与协议

- `GET /api/v1/analytics/dashboards/creator` 要求 `analytics.view` 和项目读取权限；`POST .../export` 另需 `analytics.manage`。拒绝 API Key、预期工作区不符及工作区分析请求中的 `X-Project-Id`。
- owner/admin/平台管理员按当前工作区权限查询；其他角色需当前租户/工作区内有效项目成员授权，工作区权限与项目授权取交集，逐项目裁剪生成、音频、成片、交付和账单来源。该策略遵循产品交集约束，不沿用部分旧项目入口较宽的权限合并行为。
- 对象范围目前仅接受非空且每项严格为 `project:{当前项目ID}` 的明确整项目授权。未定义的 assigned/通配符/窄对象或混合范围整体排除并提示，不猜测未规定的对象范围语法。导出范围摘要包含所有有效 assignment 的范围及权限，包括被排除项，防止收窄后重放旧报告。
- 筛选选项、分母、图表、明细与 CSV 共用相同范围；查询支持时间、项目、剧集、模型、成员、名称/ID 和分组维度，服务端稳定排序及分页。
- 来源表须在同一物理数据库。明确配置到其他数据库或无法确认的间接目标时返回 `503 ANALYTICS_SOURCE_DATABASE_MISMATCH`，不以本地空表冒充零值。规范化忽略 driver/账户与普通连接参数，仍校验数据库、主机/端口、schema 和改变目标的 query；无法解析 service 间接配置时保守拒绝，响应不包含连接 URL。
- 每个来源扫描上限 20,000 行、总事实 100,000、分组 5,000、趋势 120 桶；超限明确拒绝，不静默截断。历史记录多时短期查询也可能达到扫描上限，需要后续数据库聚合/索引与规模验收。
- CSV 覆盖完整匹配分组，不只导出前端当前页，含范围、截止时间、币种、覆盖说明及上期汇总；总行数（含统计/趋势等）不超过 1,000，文件不超过 2 MiB，并防公式注入。多币种展开为独立费用行，重复的任务/产出字段不能跨币种重复求和。
- 导出回执、AnalyticsAudit 与平台 outbox 同事务；先校验当前权限范围并查已保存回执，再决定是否重算。已成功同键重放原 CSV，不因后续记录增长或事实源掉线改变快照；授权收窄拒绝重放。同键并发、空工作区并发和回滚已验证。
- 默认时间范围/维度复用 `GET/PUT /api/v1/account/preferences` 的 `data-dashboard` resource，独立校验 `analytics.view/manage`，不能以 settings 权限绕过；按租户/工作区/操作者隔离，严格版本、CAS、稳定幂等回执、审计/outbox 同事务。
- 新迁移 `87b2b5beccc7`，父 `14332a65527a`：创建报告回执/审计表，给系统 owner/admin 合并分析权限并更新角色/工作区权限版本，保留其他权限、member 和自定义角色；更新 PostgreSQL 新工作区身份同步函数，旧默认权限全集冻结保存。未连接或变更生产数据库。
