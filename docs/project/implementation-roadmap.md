## 产品决策边界

- 确定性分镜编辑检查 v1 的时长、相邻变化和对白密度为透明编辑提示；缺必要资产引用才阻断冻结，不替代模型能力或商用内容合规。
- 原文导入成功不等于结构合格或 AI 全文处理完成；单次 AI 字符上限是应用策略，不是模型 token 容量。超限不静默截断，新增或无法证明来源的改编内容标为未映射。
- 普通用户不自动升级平台管理员，不赠送虚构余额，不生成演示任务产物。
- 真实收退款、付费模型调用、对外发布和生产部署仍需相应凭据、明确授权与验收，常规界面和本地逻辑决策由开发负责。
- 遵循用户要求，不新增或修改测试文件、测试脚本、fixtures、snapshots；用适当已有检查、构建与真实行为核验交付。
