## 随后的核心阻塞

- M03 导演版本确认与长文本编排：原文范围→各集工作稿及明确生产引用已接通；下一步区分导演候选与人工确认，并让下游引用确认版本。章节语义映射、局部回滚和长文本自动编排仍是实现缺口，不能只列为缺少外部凭据。
- M05/M06 精确资产输入：把镜头冻结资产版本传入供应商请求并在解析器强制核验；当前只传资产 ID，不能把镜头记录不可变等同于外部生成输入已验证。
- M09 多集并行结算：按精确成片时间线追溯相关生成／音频／渲染任务，修正其他集未结算任务挡住当前集导出的问题，并明确共享素材成本归属。
- 项目预算硬限制：放入 M06/M07/M08 同库账户锁及冻结事务，核对币种、历史结算、有效预留、重试及预算下调权限；不能以看板先查后写代替原子约束。
- 核心生产联合验收：同一项目从原文、导演、资产、分镜、真实生成/配音到成片、审核和交付。外部模型、渲染、商户及审核凭据未配置时保持明确不可用。
- 专用团队与后台体验、企业身份/MFA、实际开票与对账、开放 API 业务入口和 Webhook 投递、实际发布回执及生产恢复演练继续分切片推进。
- 继续统一项目内剩余表单、空状态和负责人等身份显示，按真实业务名称与权限信息呈现，避免将内部标识误当作姓名。

## 产品决策边界

- 确定性分镜编辑检查 v1 的时长、相邻变化和对白密度为透明编辑提示；缺必要资产引用才阻断冻结，不替代模型能力或商用内容合规。
- 原文导入成功不等于结构合格或 AI 全文处理完成；单次 AI 字符上限是应用策略，不是模型 token 容量。超限不静默截断，新增或无法证明来源的改编内容标为未映射。
- 普通用户不自动升级平台管理员，不赠送虚构余额，不生成演示任务产物。
- 真实收退款、付费模型调用、对外发布和生产部署仍需相应凭据、明确授权与验收，常规界面和本地逻辑决策由开发负责。
- 遵循用户要求，不新增或修改测试文件、测试脚本、fixtures、snapshots；用适当已有检查、构建与真实行为核验交付。
