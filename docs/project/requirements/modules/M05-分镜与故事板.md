本模块统一承载「分镜与故事板」相关需求。模块内页面、接口、数据、权限、异常与验收必须作为同一能力集合维护，不允许只完成可见页面而遗漏服务端规则或失败路径。

- 下游能力：图片、视频、音频生产
- 页面只做范围映射；模块完成必须通过联合验收，不以单页可打开为完成。

1. 前置依赖真实可用，权限和租户上下文贯穿全流程；
2. 模块内数据对象、状态机、API 和页面展示一致；

5. 下游模块能够消费本模块产物，刷新或重复请求不产生重复副作用。

## 5. 详细功能需求

### CR-079 提示词中心

- 系统：创作者
- 路由：`creator/prompt-center.html`
- 阶段：P0
- 当前状态：未开始


| 属性 | 规格 |
|---|---|
| 系统 | 创作者前台 |
| 原型路由 | `creator/prompt-center.html` |
| 业务域 | 分镜与故事板 |
| 阶段 | P0 |
| 主要用户 | 分镜师、导演、视觉师 |

### 页面目标

管理图片和视频提示词模板、变量、负面词、模型适配版本及其镜头使用记录。

### 入口、前置与退出

- 进入页面前必须解析当前工作区；项目内页面还必须解析项目、剧集或对象上下文。
- 入口可以来自所属一级模块、对象详情、任务/通知深链或具备权限的关联页面。
- 返回列表时恢复筛选、分页和滚动；深链跳转保留工作区与对象上下文。

### 页面区域、字段与操作

- 顶部区域必须展示页面标题、当前上下文、关键状态和主操作。
- 主内容区展示与 `提示词中心` 直接相关的数据，不使用与业务无关的通用占位卡片。
  - 操作：查看镜头顺序与依赖
  - 操作：生成或编辑镜头
  - 操作：批量校验并保存版本
  - 字段：镜头 ID
  - 字段：镜号/顺序
  - 字段：景别/运镜
  - 字段：角色/场景引用
  - 字段：台词/时长
  - 字段：提示词
  - 字段：版本/状态
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `Shot`
  - `ShotVersion`
  - `Storyboard`
  - `Prompt`
  - `AssetReference`
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - `shot.view`
  - `shot.manage`
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：恢复当前工作区、项目、剧集及对象版本。
  - 编辑态：自动保存显示保存中/已保存/冲突，冲突不得静默覆盖。
  - 异常态：权限变化、对象删除、版本冲突和前置条件未满足均提供恢复路径。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。

### 接口依赖

  - `GET /api/v1/projects/{projectId}/shots`
  - `POST /api/v1/projects/{projectId}/shots/actions`
- 通用依赖：`GET /api/v1/session/context` 获取当前用户、工作区、角色和功能开关。

### 验收标准

1. 具备权限的 分镜师、导演、视觉师 能从规定入口进入 `提示词中心`，页面上下文、标题和数据范围正确。
2. 无权限用户直接访问路由时服务端返回 403，页面不泄露对象名称、媒体地址或敏感字段。
3. 页面加载、空数据、处理中、成功、失败和并发冲突状态均有明确反馈和可执行恢复动作。
4. 所有写操作通过服务端校验、幂等和乐观锁；成功后重新读取的数据与提交结果一致。
5. 审计要求覆盖的操作可以按请求 ID、操作者和业务对象检索。
6. 页面接口失败不会丢失已保存数据，也不会产生重复任务、重复扣费或重复审批。

| 原型路由 | `creator/shot-version-compare.html` |
| 业务域 | 分镜与故事板 |
| 阶段 | P1 |
| 主要用户 | 分镜师、导演、视觉师 |

### 页面目标

对比 AI 版本、人工调整版、锁定版和生成版差异。

### 入口、前置与退出

- 进入页面前必须解析当前工作区；项目内页面还必须解析项目、剧集或对象上下文。
- 入口可以来自所属一级模块、对象详情、任务/通知深链或具备权限的关联页面。
- 返回列表时恢复筛选、分页和滚动；深链跳转保留工作区与对象上下文。

### 页面区域、字段与操作

- 顶部区域必须展示页面标题、当前上下文、关键状态和主操作。
- 主内容区展示与 `分镜版本对比` 直接相关的数据，不使用与业务无关的通用占位卡片。
  - 操作：查看镜头顺序与依赖
  - 操作：生成或编辑镜头
  - 操作：批量校验并保存版本
  - 操作：并排查看差异并选择保留版本
  - 字段：镜头 ID
  - 字段：镜号/顺序
  - 字段：景别/运镜
  - 字段：角色/场景引用
  - 字段：台词/时长
  - 字段：提示词
  - 字段：版本/状态
  - 字段：基准版本
  - 字段：候选版本
  - 字段：差异项
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `Shot`
  - `ShotVersion`
  - `Storyboard`
  - `Prompt`
  - `AssetReference`
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - `shot.view`
  - `shot.manage`
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：恢复当前工作区、项目、剧集及对象版本。
  - 编辑态：自动保存显示保存中/已保存/冲突，冲突不得静默覆盖。
  - 异常态：权限变化、对象删除、版本冲突和前置条件未满足均提供恢复路径。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。

### 接口依赖

  - `GET /api/v1/projects/{projectId}/shots`
  - `POST /api/v1/projects/{projectId}/shots/actions`
- 通用依赖：`GET /api/v1/session/context` 获取当前用户、工作区、角色和功能开关。

### 验收标准

1. 具备权限的 分镜师、导演、视觉师 能从规定入口进入 `分镜版本对比`，页面上下文、标题和数据范围正确。
2. 无权限用户直接访问路由时服务端返回 403，页面不泄露对象名称、媒体地址或敏感字段。
3. 页面加载、空数据、处理中、成功、失败和并发冲突状态均有明确反馈和可执行恢复动作。
4. 所有写操作通过服务端校验、幂等和乐观锁；成功后重新读取的数据与提交结果一致。
5. 审计要求覆盖的操作可以按请求 ID、操作者和业务对象检索。
6. 页面接口失败不会丢失已保存数据，也不会产生重复任务、重复扣费或重复审批。
