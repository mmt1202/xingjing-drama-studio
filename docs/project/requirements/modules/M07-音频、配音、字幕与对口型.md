# M07 音频、配音、字幕与对口型需求设计

- 范围：音频字幕与对口型
- 页面覆盖：7 项（P0=1，P1=6，P2=0）
- 完成度：0/7 已验证
- 当前状态：开发中
- 联合验收包：A6 音频字幕闭环

- 当前实现证据：EV-M07-PERSISTENCE-001、EV-M07-RUNTIME-HTTP-002、EV-M07-CANCEL-STATE-003、EV-M07-FRONTEND-AUTH-004
- 状态说明：PostgreSQL 持久化、可信会话、运行时、HTTP 与音频工作台已存在；工作台读取真实轨道、提交版本与媒体任务，使用当前 Bearer 会话且不发送可伪造工作区头。对象存储、Provider、真实部署与 A6 联合验收仍未完成，因此模块保持开发中。

## 1. 模块目标与边界

本模块统一承载「音频、配音、字幕与对口型」相关需求。模块内页面、接口、数据、权限、异常与验收必须作为同一能力集合维护，不允许只完成可见页面而遗漏服务端规则或失败路径。

- 前置依赖：M03、M05、M06、对象存储
- 下游能力：成片合成与交付
- 页面只做范围映射；模块完成必须通过联合验收，不以单页可打开为完成。

## 4. 联合验收要求

本模块并入「A6 音频字幕闭环」验收，不单独以页面数量结项。验收至少覆盖：

1. 前置依赖真实可用，权限和租户上下文贯穿全流程；
2. 模块内数据对象、状态机、API 和页面展示一致；
3. 正常、空、失败、冲突、取消、超时、重试和恢复路径按适用范围通过；
4. 模块产生的任务、费用、审计、合规和版本证据可以追踪；
5. 下游模块能够消费本模块产物，刷新或重复请求不产生重复副作用。

## 5. 详细功能需求

### CR-007 音频字幕

- 系统：创作者
- 路由：`creator/audio-subtitle.html`
- 阶段：P0
- 当前状态：未开始


| 属性 | 规格 |
|---|---|
| 系统 | 创作者前台 |
| 原型路由 | `creator/audio-subtitle.html` |
| 业务域 | 音频字幕与对口型 |
| 阶段 | P0 |
| 主要用户 | 音频师、剪辑师 |

### 页面目标

统一管理角色音色、配音片段、字幕轨、BGM 与音效，并把确认版本交给成片时间线。

### 入口、前置与退出

- 进入页面前必须解析当前工作区；项目内页面还必须解析项目、剧集或对象上下文。
- 入口可以来自所属一级模块、对象详情、任务/通知深链或具备权限的关联页面。
- 返回列表时恢复筛选、分页和滚动；深链跳转保留工作区与对象上下文。

### 页面区域、字段与操作

- 顶部区域必须展示页面标题、当前上下文、关键状态和主操作。
- 主内容区展示与 `音频字幕` 直接相关的数据，不使用与业务无关的通用占位卡片。
  - 操作：绑定角色、音频或字幕轨
  - 操作：生成并预览结果
  - 操作：校准时间并保存版本
  - 字段：轨道/片段 ID
  - 字段：角色/音色
  - 字段：语言
  - 字段：起止时间
  - 字段：文本
  - 字段：版本/状态
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `AudioClip`
  - `SubtitleTrack`
  - `LipSyncVersion`
  - `GenerationTask`
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - `audio.view`
  - `audio.manage`
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：展示骨架屏并保留页面结构。
  - 空状态：说明无数据原因并提供当前用户有权限的下一步。
  - 异常态：区分无权限、无数据、服务失败和并发冲突。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。

### 接口依赖

  - `GET /api/v1/projects/{projectId}/audio-tracks`
  - `POST /api/v1/projects/{projectId}/audio-actions`
- 通用依赖：`GET /api/v1/session/context` 获取当前用户、工作区、角色和功能开关。

### 验收标准

1. 具备权限的 音频师、剪辑师 能从规定入口进入 `音频字幕`，页面上下文、标题和数据范围正确。
2. 无权限用户直接访问路由时服务端返回 403，页面不泄露对象名称、媒体地址或敏感字段。
3. 页面加载、空数据、处理中、成功、失败和并发冲突状态均有明确反馈和可执行恢复动作。
4. 所有写操作通过服务端校验、幂等和乐观锁；成功后重新读取的数据与提交结果一致。
5. 审计要求覆盖的操作可以按请求 ID、操作者和业务对象检索。
6. 页面接口失败不会丢失已保存数据，也不会产生重复任务、重复扣费或重复审批。
