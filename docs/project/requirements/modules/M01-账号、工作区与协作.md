- 当前状态：开发中

## 1. 模块目标与边界

本模块统一承载「账号、工作区与协作」相关需求。模块内页面、接口、数据、权限、异常与验收必须作为同一能力集合维护，不允许只完成可见页面而遗漏服务端规则或失败路径。

- 前置依赖：平台共享地基
- 下游能力：项目创建、团队协作、所有租户业务
- 页面只做范围映射；模块完成必须通过联合验收，不以单页可打开为完成。

## 4. 联合验收要求

本模块并入「A0 身份与租户地基闭环」验收，不单独以页面数量结项。验收至少覆盖：

1. 前置依赖真实可用，权限和租户上下文贯穿全流程；
2. 模块内数据对象、状态机、API 和页面展示一致；
3. 正常、空、失败、冲突、取消、超时、重试和恢复路径按适用范围通过；
4. 模块产生的任务、费用、审计、合规和版本证据可以追踪；
5. 下游模块能够消费本模块产物，刷新或重复请求不产生重复副作用。

## 5. 详细功能需求

### CR-039 忘记密码

- 系统：创作者
- 路由：`creator/forgot-password.html`
- 阶段：P0
- 当前状态：未开始


| 属性 | 规格 |
|---|---|
| 系统 | 创作者前台 |
| 原型路由 | `creator/forgot-password.html` |
| 业务域 | 账号与访问 |
| 阶段 | P0 |
| 主要用户 | 注册用户、账号所有者 |

### 页面目标

邮箱 / 手机号验证码找回密码，并记录安全事件。

### 入口、前置与退出

- 进入页面前必须解析当前工作区；项目内页面还必须解析项目、剧集或对象上下文。
- 入口可以来自所属一级模块、对象详情、任务/通知深链或具备权限的关联页面。
- 返回列表时恢复筛选、分页和滚动；深链跳转保留工作区与对象上下文。

### 页面区域、字段与操作

- 顶部区域必须展示页面标题、当前上下文、关键状态和主操作。
- 主内容区展示与 `忘记密码` 直接相关的数据，不使用与业务无关的通用占位卡片。
  - 操作：校验身份或会话
  - 操作：查看安全状态
  - 操作：执行受控账号操作
  - 操作：验证验证码/旧凭证并设置新密码
  - 字段：账号标识
  - 字段：验证方式
  - 字段：会话/设备
  - 字段：安全状态
  - 字段：最近操作时间
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `User`
  - `UserCredential`
  - `LoginSession`
  - `SecurityEvent`
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - `account.view`
  - `account.manage`
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：以服务端会话和权限为准。
  - 禁用态：无权限操作不渲染或禁用并说明原因，接口仍必须拒绝。
  - 异常态：登录风险、验证失败和会话失效不得泄露账号是否存在。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。

### 接口依赖

  - `GET /api/v1/account/profile`
  - `POST /api/v1/auth/actions`
- 通用依赖：`GET /api/v1/session/context` 获取当前用户、工作区、角色和功能开关。

### 验收标准

1. 具备权限的 注册用户、账号所有者 能从规定入口进入 `忘记密码`，页面上下文、标题和数据范围正确。
2. 无权限用户直接访问路由时服务端返回 403，页面不泄露对象名称、媒体地址或敏感字段。
3. 页面加载、空数据、处理中、成功、失败和并发冲突状态均有明确反馈和可执行恢复动作。
4. 所有写操作通过服务端校验、幂等和乐观锁；成功后重新读取的数据与提交结果一致。
5. 审计要求覆盖的操作可以按请求 ID、操作者和业务对象检索。
6. 页面接口失败不会丢失已保存数据，也不会产生重复任务、重复扣费或重复审批。

- 主内容区展示与 `团队空间` 直接相关的数据，不使用与业务无关的通用占位卡片。
  - 操作：查看工作区范围
  - 操作：维护成员或配置
  - 操作：查看变更记录
  - 字段：工作区 ID
  - 字段：成员/角色
  - 字段：数据范围
  - 字段：席位/套餐
  - 字段：状态
  - 字段：更新时间
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `Workspace`
  - `WorkspaceMember`
  - `Role`
  - `Permission`
  - `AuditLog`
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - `workspace.view`
  - `workspace.manage`
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：展示骨架屏并保留页面结构。
  - 空状态：说明无数据原因并提供当前用户有权限的下一步。
  - 异常态：区分无权限、无数据、服务失败和并发冲突。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。

### 接口依赖

  - `GET /api/v1/workspaces/{workspaceId}`
  - `POST /api/v1/workspaces/{workspaceId}/actions`
- 通用依赖：`GET /api/v1/session/context` 获取当前用户、工作区、角色和功能开关。

### 验收标准

1. 具备权限的 工作区所有者、团队管理员、项目负责人 能从规定入口进入 `团队空间`，页面上下文、标题和数据范围正确。
2. 无权限用户直接访问路由时服务端返回 403，页面不泄露对象名称、媒体地址或敏感字段。
3. 页面加载、空数据、处理中、成功、失败和并发冲突状态均有明确反馈和可执行恢复动作。
4. 所有写操作通过服务端校验、幂等和乐观锁；成功后重新读取的数据与提交结果一致。
5. 审计要求覆盖的操作可以按请求 ID、操作者和业务对象检索。
6. 页面接口失败不会丢失已保存数据，也不会产生重复任务、重复扣费或重复审批。
