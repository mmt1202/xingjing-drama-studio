## 1. 模块目标与边界

本模块统一承载「审片协作与客户交付」相关需求。模块内页面、接口、数据、权限、异常与验收必须作为同一能力集合维护，不允许只完成可见页面而遗漏服务端规则或失败路径。

- 前置依赖：M08、M09、M10、外链安全
- 下游能力：客户批注、审批和交付确认
- 页面只做范围映射；模块完成必须通过联合验收，不以单页可打开为完成。

## 4. 联合验收要求

本模块并入「B3 客户审片交付闭环」验收，不单独以页面数量结项。验收至少覆盖：

1. 前置依赖真实可用，权限和租户上下文贯穿全流程；
2. 模块内数据对象、状态机、API 和页面展示一致；
3. 正常、空、失败、冲突、取消、超时、重试和恢复路径按适用范围通过；
4. 模块产生的任务、费用、审计、合规和版本证据可以追踪；
5. 下游模块能够消费本模块产物，刷新或重复请求不产生重复副作用。

## 5. 详细功能需求

### CL-001 客户确认交付

- 系统：客户审片
- 路由：`client/client-review-approve.html`
- 阶段：P1
- 当前状态：未开始


| 属性 | 规格 |
|---|---|
| 系统 | 客户审片 Web/H5 |
| 原型路由 | `client/client-review-approve.html` |
| 业务域 | 客户审片 |
| 阶段 | P1 |
| 主要用户 | 客户/甲方审阅者 |

### 页面目标

确认通过、打回修改、补充意见和验收记录签收。

### 入口、前置与退出

- 进入页面前必须验证外链 token、有效期、访问策略和可见版本。
- 入口可以来自所属一级模块、对象详情、任务/通知深链或具备权限的关联页面。
- 退出后清理外链会话；返回保持当前审片版本和时间点。

### 页面区域、字段与操作

- 顶部区域必须展示页面标题、当前上下文、关键状态和主操作。
- 主内容区展示与 `客户确认交付` 直接相关的数据，不使用与业务无关的通用占位卡片。
  - 操作：查看可审版本
  - 操作：提交时间点反馈
  - 操作：通过或打回受控版本
  - 操作：记录通过/打回结论和签收证据
  - 字段：审片链接/会话 ID
  - 字段：可见版本
  - 字段：有效期
  - 字段：访问策略
  - 字段：时间点批注
  - 字段：审批状态
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `ReviewLink`
  - `ReviewSession`
  - `ReviewComment`
  - `ApprovalRecord`
  - `FinalVideoVersion`
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - `review.view`
  - `review.approve`
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：验证外链有效期、访问策略和可见版本。
  - 协作态：批注提交后显示时间点、提交人和处理状态。
  - 异常态：过期、撤销、超限、版本删除分别给出明确结果且不泄露项目信息。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。

### 接口依赖

  - `GET /api/v1/review-links/{token}/context`
  - `POST /api/v1/review-links/{token}/actions`
- 通用依赖：`GET /api/v1/session/context` 获取当前用户、工作区、角色和功能开关。

### 验收标准

1. 具备权限的 客户/甲方审阅者 能从规定入口进入 `客户确认交付`，页面上下文、标题和数据范围正确。
2. 无权限用户直接访问路由时服务端返回 403，页面不泄露对象名称、媒体地址或敏感字段。
3. 页面加载、空数据、处理中、成功、失败和并发冲突状态均有明确反馈和可执行恢复动作。
4. 所有写操作通过服务端校验、幂等和乐观锁；成功后重新读取的数据与提交结果一致。
5. 审计要求覆盖的操作可以按请求 ID、操作者和业务对象检索。
6. 页面接口失败不会丢失已保存数据，也不会产生重复任务、重复扣费或重复审批。

  - 字段：可见版本
  - 字段：有效期
  - 字段：访问策略
  - 字段：时间点批注
  - 字段：审批状态
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `ReviewLink`
  - `ReviewSession`
  - `ReviewComment`
  - `ApprovalRecord`
  - `FinalVideoVersion`
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - `review.view`
  - `review.manage`
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：验证外链有效期、访问策略和可见版本。
  - 协作态：批注提交后显示时间点、提交人和处理状态。
  - 异常态：过期、撤销、超限、版本删除分别给出明确结果且不泄露项目信息。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。

### 接口依赖

  - `GET /api/v1/workspaces/{workspaceId}/review-links`
  - `POST /api/v1/workspaces/{workspaceId}/review-links`
- 通用依赖：`GET /api/v1/session/context` 获取当前用户、工作区、角色和功能开关。

### 验收标准

1. 具备权限的 团队管理员、项目负责人 能从规定入口进入 `客户审片`，页面上下文、标题和数据范围正确。
2. 无权限用户直接访问路由时服务端返回 403，页面不泄露对象名称、媒体地址或敏感字段。
3. 页面加载、空数据、处理中、成功、失败和并发冲突状态均有明确反馈和可执行恢复动作。
4. 所有写操作通过服务端校验、幂等和乐观锁；成功后重新读取的数据与提交结果一致。
5. 审计要求覆盖的操作可以按请求 ID、操作者和业务对象检索。
6. 页面接口失败不会丢失已保存数据，也不会产生重复任务、重复扣费或重复审批。
