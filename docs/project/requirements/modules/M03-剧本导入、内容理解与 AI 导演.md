- 前置依赖：M01、M02、模型与任务能力

- 页面只做范围映射；模块完成必须通过联合验收，不以单页可打开为完成。

## 5. 详细功能需求

### CR-003 AI导演

- 系统：创作者
- 路由：`creator/ai-director.html`
- 阶段：P0
- 当前状态：待验收


| 属性 | 规格 |
|---|---|
| 系统 | 创作者前台 |
| 原型路由 | `creator/ai-director.html` |
| 业务域 | 剧本与导演 |
| 阶段 | P0 |
| 主要用户 | 编剧、导演、项目负责人 |

### 页面目标

基于冻结剧本版本生成并确认受众、节奏、镜头语言、风格和制作约束，作为资产与分镜的上游设定。

### 入口、前置与退出

- 进入页面前必须解析当前工作区；项目内页面还必须解析项目、剧集或对象上下文。
- 入口可以来自所属一级模块、对象详情、任务/通知深链或具备权限的关联页面。
- 返回列表时恢复筛选、分页和滚动；深链跳转保留工作区与对象上下文。

### 页面区域、字段与操作

- 顶部区域必须展示页面标题、当前上下文、关键状态和主操作。
- 主内容区展示与 `AI导演` 直接相关的数据，不使用与业务无关的通用占位卡片。
  - 操作：读取原文与当前版本
  - 操作：编辑或生成内容
  - 操作：对比并冻结版本
  - 字段：剧本 ID
  - 字段：来源章节
  - 字段：当前版本
  - 字段：人物/场景
  - 字段：节奏/风格
  - 字段：锁定状态
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `Script`
  - `ScriptVersion`
  - `SourceMapping`
  - `DirectorProfile`
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - `script.view`
  - `script.manage`
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：恢复当前工作区、项目、剧集及对象版本。
  - 编辑态：自动保存显示保存中/已保存/冲突，冲突不得静默覆盖。
  - 异常态：权限变化、对象删除、版本冲突和前置条件未满足均提供恢复路径。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。

### 接口依赖

  - `GET /api/v1/projects/{projectId}/scripts`
  - `POST /api/v1/projects/{projectId}/scripts/actions`
- 通用依赖：`GET /api/v1/session/context` 获取当前用户、工作区、角色和功能开关。

### 验收标准

1. 具备权限的 编剧、导演、项目负责人 能从规定入口进入 `AI导演`，页面上下文、标题和数据范围正确。
2. 无权限用户直接访问路由时服务端返回 403，页面不泄露对象名称、媒体地址或敏感字段。
3. 页面加载、空数据、处理中、成功、失败和并发冲突状态均有明确反馈和可执行恢复动作。
4. 所有写操作通过服务端校验、幂等和乐观锁；成功后重新读取的数据与提交结果一致。
5. 审计要求覆盖的操作可以按请求 ID、操作者和业务对象检索。
6. 页面接口失败不会丢失已保存数据，也不会产生重复任务、重复扣费或重复审批。

| 属性 | 规格 |

### 页面目标

对比原文、改写版、审稿版和冻结版差异，可局部回滚。

### 入口、前置与退出

- 进入页面前必须解析当前工作区；项目内页面还必须解析项目、剧集或对象上下文。
- 入口可以来自所属一级模块、对象详情、任务/通知深链或具备权限的关联页面。
- 返回列表时恢复筛选、分页和滚动；深链跳转保留工作区与对象上下文。

### 页面区域、字段与操作

- 顶部区域必须展示页面标题、当前上下文、关键状态和主操作。
- 主内容区展示与 `剧本版本对比` 直接相关的数据，不使用与业务无关的通用占位卡片。
  - 操作：读取原文与当前版本
  - 操作：编辑或生成内容
  - 操作：对比并冻结版本
  - 操作：并排查看差异并选择保留版本
  - 字段：剧本 ID
  - 字段：来源章节
  - 字段：当前版本
  - 字段：人物/场景
  - 字段：节奏/风格
  - 字段：锁定状态
  - 字段：基准版本
  - 字段：候选版本
  - 字段：差异项
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `Script`
  - `ScriptVersion`
  - `SourceMapping`
  - `DirectorProfile`
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - `script.view`
  - `script.manage`
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：恢复当前工作区、项目、剧集及对象版本。
  - 编辑态：自动保存显示保存中/已保存/冲突，冲突不得静默覆盖。
  - 异常态：权限变化、对象删除、版本冲突和前置条件未满足均提供恢复路径。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。
