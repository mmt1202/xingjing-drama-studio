- 范围：团队计费与成本
- 页面覆盖：5 项（P0=0，P1=5，P2=0）
- 完成度：0/5 已验证
- 当前状态：开发中
- 联合验收包：B2 团队财务闭环

- 当前实现证据：EV-M11-FINANCE-001、EV-M11-FRONTEND-002、EV-M11-API-003、EV-M11-BASELINE-004
- 状态说明：账单、冻结与流水读取、套餐展示、多维成本筛选、同条件 CSV 导出及带审计的发票申请已实现并完成代码级验证。真实 PostgreSQL/Java 身份、支付/退款通道与 B2 联合验收仍未完成，不能据此计入已验证。

## 1. 模块目标与边界

本模块统一承载「团队计费、成本与权益」相关需求。模块内页面、接口、数据、权限、异常与验收必须作为同一能力集合维护，不允许只完成可见页面而遗漏服务端规则或失败路径。

- 前置依赖：M10、算力账务、订单与发票
- 下游能力：团队成本控制和财务对账
- 页面只做范围映射；模块完成必须通过联合验收，不以单页可打开为完成。

- 复用既有生成/音频/剪辑账务与团队财务表，读取共享事务快照，不增加第二套余额或迁移。

本模块并入「B2 团队财务闭环」验收，不单独以页面数量结项。验收至少覆盖：

1. 前置依赖真实可用，权限和租户上下文贯穿全流程；
2. 模块内数据对象、状态机、API 和页面展示一致；
3. 正常、空、失败、冲突、取消、超时、重试和恢复路径按适用范围通过；
4. 模块产生的任务、费用、审计、合规和版本证据可以追踪；
5. 下游模块能够消费本模块产物，刷新或重复请求不产生重复副作用。

## 5. 详细功能需求

### TM-001 团队账单

- 系统：团队
- 路由：`team/team-billing.html`
- 阶段：P1
- 当前状态：开发中


| 属性 | 规格 |
|---|---|
| 系统 | 团队/企业后台 |
| 原型路由 | `team/team-billing.html` |
| 业务域 | 团队计费与成本 |
| 阶段 | P1 |
| 主要用户 | 团队所有者、团队财务、项目负责人 |

### 页面目标

查看团队套餐、席位、算力账户、订单、发票和账务入口，并限制财务数据范围。

### 入口、前置与退出

- 进入页面前必须解析团队工作区及管理员数据范围。
- 入口可以来自所属一级模块、对象详情、任务/通知深链或具备权限的关联页面。
- 返回列表时恢复筛选、分页和滚动；深链跳转保留工作区与对象上下文。

### 页面区域、字段与操作

- 顶部区域必须展示页面标题、当前上下文、关键状态和主操作。
- 主内容区展示与 `团队账单` 直接相关的数据，不使用与业务无关的通用占位卡片。
  - 操作：查看余额/成本/流水
  - 操作：筛选并导出账务数据
  - 操作：发起有审计的财务操作
  - 字段：账户/流水 ID
  - 字段：业务单据号
  - 字段：金额/算力最小单位
  - 字段：冻结/结算状态
  - 字段：关联任务
  - 字段：发生时间
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `CreditAccount`
  - `CreditHold`
  - `CreditTransaction`
  - `Order`
  - `Invoice`
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - `billing.view`
  - `billing.manage`
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：余额、冻结额和流水使用同一结算快照。
  - 空状态：无流水时展示计费说明，不伪造示例金额。
  - 异常态：对账不平、重复回调或退款处理中显示工单/人工复核编号。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。

### 接口依赖

  - `GET /api/v1/workspaces/{workspaceId}/billing`
  - `GET /api/v1/workspaces/{workspaceId}/costs`
- 通用依赖：`GET /api/v1/session/context` 获取当前用户、工作区、角色和功能开关。

### 验收标准

1. 具备权限的 团队所有者、团队财务、项目负责人 能从规定入口进入 `团队账单`，页面上下文、标题和数据范围正确。
2. 无权限用户直接访问路由时服务端返回 403，页面不泄露对象名称、媒体地址或敏感字段。
3. 页面加载、空数据、处理中、成功、失败和并发冲突状态均有明确反馈和可执行恢复动作。
4. 所有写操作通过服务端校验、幂等和乐观锁；成功后重新读取的数据与提交结果一致。
5. 审计要求覆盖的操作可以按请求 ID、操作者和业务对象检索。
6. 页面接口失败不会丢失已保存数据，也不会产生重复任务、重复扣费或重复审批。
