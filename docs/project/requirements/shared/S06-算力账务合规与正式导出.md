## 联合验收

执行成功、余额不足、供应商失败、取消、超时、重复回调、部分失败和晚回调；随后执行合规通过、阻断、申诉、项目变更失效和正式导出，证明账务守恒且门禁不可绕过。

当前实施证据：`EV-M09-RUNTIME-001`、`EV-M09-PERSISTENCE-003`、`EV-M09-RUNTIME-HTTP-004`、`EV-M09-FRONTEND-AUTH-005`。M09 前端只读取服务端权威证据、交付记录并执行非交付预检；未选定项目版本或导出目标时不发请求，正式导出仍由服务端拒绝。账务、真实审核/授权事实、媒体执行器、对象存储、下载与 A8 联合验收仍未完成。
