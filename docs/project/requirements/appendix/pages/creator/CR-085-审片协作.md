## 完整页面需求

### 页面目标

在项目内部对精确成片版本组织审片回合，播放视频、记录镜头/时间点批注、处理问题、通过或打回并锁定历史，再交接发布包。客户外链与客户签收继续由 CR-011 / CL 页面承接。

### 入口、前置与退出

- 正式页面为 `/app/workspaces/{workspaceId}/projects/{projectId}/collaboration/CR-085`，复用项目阶段导航和可信工作区/项目上下文。
- 保留剧集、成片版本、时间线与回合上下文；地址中筛选/分页可恢复，深链不匹配时明确拒绝读取错误对象。
- 返回剪辑携带当前时间线；客户外链管理预填当前成片版本；交接发布包保留精确版本、剧集、时间线和数据库中的发布目标。
- 未保存草稿拦截页面内切换与阶段导航，并保护刷新；失败保留输入，允许显式放弃草稿。

### 页面区域、字段与操作

- 沿用原型同屏布局：左侧播放器、时间点表单与镜头批注，右侧回合进度、未处理数、处理结论、继续收集、通过/打回、锁定和发布包入口。
- 从真实不可变成片目录选择版本创建回合，不接受任意伪造版本；同一剧集上一回合锁定后才可创建下一回合，不同剧集可同时审片。
- 回合列表支持名称/ID/结论、状态、成片和剧集组合筛选以及稳定服务端分页，详情显示回合 ID、记录版本和更新时间。
- 播放器与批注共享播放位置；点击批注时间跳转，使用当前播放位置可创建毫秒精度批注。镜头范围来自该成片的冻结时间线。
- 根问题记录作者、时间点、镜头、内容、重要程度、处理状态和版本；回复沿用根问题的时间点与镜头，不创建嵌套回复。
- 处理状态只展示合法转换。全部根问题解决后才可通过；打回需要处理说明，通过备注可空。
- 审批后显式锁定；锁定后保留只读记录。未锁定的决定可继续收集，新根问题或状态变化会清除旧决定，回复不修改审批结论。
- 缺少文件、损坏文件、观看票据失效与服务故障给出恢复提示；媒体不可用时仍可读取审片历史。

### 数据对象与业务规则

- `InternalReviewRound`、`InternalReviewComment`、`InternalReviewCommand`、`FinalVideoVersion`、`TimelineVersion`，复用 `ReviewAudit` 和平台 outbox。
- 回合固定不可变成片版本，不覆盖旧版本或旧回合，不把内部通过写成客户签收。
- 创建时验证真实成片对象的安全路径、大小、SHA256 和时长；时间点必须在成片时长及所选镜头半开区间内。
- 写入携带 `Idempotency-Key`；更新携带回合 `version`，问题状态还携带问题版本。同键/正文返回原回执，旧版本/锁定/状态冲突返回 409。
- 项目锁串行化编号及版本更新；回合/批注、回执、完整前后审计与 outbox 同事务，失败整体回滚。
- 已通过且锁定才可调用受控交接，服务端返回精确导航上下文；交接不创建发布包，正式导出仍通过其既有权限、合规及交付检查。

### 权限与数据范围

- `review.view` 读取内部回合与受控媒体；`review.manage` 创建、批注、处理、决定及锁定。交接还需 `export.view`。
- 每次业务请求验证可信租户/工作区/项目，拒绝 API Key；请求预期工作区与会话不一致时拒绝。
- 媒体使用不含 Bearer 的 120 秒签名读取票据，绑定租户/工作区/项目/回合/成片/回合版本和签发操作者；取流校验项目存续、版本与对象完整性。
- 已签发媒体票据是一项短期读取能力；其剩余有效期内不重新查询身份服务。业务权限撤销下次请求生效，不代表旧媒体票据立即失效；回合版本改变或票据到期后旧票据失效。
- 审计含操作者、请求 ID、对象、时间、动作和前后摘要，问题状态操作保留问题旧/新快照。

### 页面状态与异常

- 区分无成片、无回合、筛选无结果、只读、锁定、媒体不可用、服务未配置和版本冲突。
- 相同不确定请求重试复用幂等键；成功后回读服务器状态，失败不清空草稿。
- 409 保留编辑并停止旧版本写入，提供显式放弃/重读；读取取消过期请求，刷新同一回合保持其他表单草稿。
- 没有创建或修改测试文件、测试脚本、夹具或快照；验证使用已有测试、静态检查及标准输入执行的直接业务行为。

### 接口依赖

- `GET/POST /api/v1/projects/{projectId}/internal-reviews`：目录与创建回合。
- `GET /api/v1/projects/{projectId}/internal-reviews/{roundId}`：精确成片、回合、批注、权限与短期媒体票据。
- `POST .../{roundId}/comments` 和 `POST .../{roundId}/comments/{commentId}/status`：批注/回复与状态转换。
- `POST .../{roundId}/decision`、`/reopen`、`/lock`：受控决定、继续收集与锁定。
- `POST .../{roundId}/handoff`：已通过且锁定版本的受控交接。
- `GET /api/v1/internal-review-media/{roundId}?ticket=...`：受控媒体读取。
- 新迁移 `14332a65527a` 继承 `a3c955c19e21`；真实部署前执行迁移，没有修改用户生产数据库。

### 验收标准

1. 成片、时间点、镜头、回合与批注保持精确版本关系；切换范围不串数据，页面使用 zh/en/vi 文本。
2. 只有可信成员能读取，管理与交接权限由服务端检查；跨租户/工作区/项目及 API Key 被拒绝。
3. 批注、回复、合法状态、通过前门禁、打回原因、继续收集和锁定均有真实持久化结果。
4. 锁定后不可继续修改；新一轮保持独立历史；旧版本并发写入不覆盖，重试不重复回合或批注。
5. 已审旧版本在存在新版本时交接，仍使用所审版本和可信发布目标；不将导航交接描述为发布成功。
6. 直接 HTTP、已有测试和浏览器证据见 EV-M12-INTERNAL-006；真实 PostgreSQL/Java、对象存储部署及 B3 联合验收后方可晋级已验证。
