### 页面目标

提供平台级创作入口、最近项目、快速入口、真实生成任务和可访问模板；项目的生产阶段导航保留在项目内。

### 入口、前置与退出

- 以可信会话解析当前用户与工作区，URL 范围不一致时拒绝并提供重新选择入口。
- 工作区提供创作首页、项目库、新建项目、全局资产库、模板与分支、任务中心、算力账单、商单中心、团队空间、数据看板、设置共 11 项一级入口；无权限或未开放入口显示禁用原因。
- 项目库、资产库及已接入的工作区模块共享一级导航。旧版项目列表提供创作首页入口；原有默认路由保持兼容。
- 首页返回状态按用户与工作区保存搜索、时间、状态、类型、分页和滚动位置；深链保留工作区、项目及任务 ID。
- 素材或偏好未保存、操作执行中禁止通过首页导航离开，刷新与关闭有未保存保护。

### 页面区域、字段与操作

- 故事输入区提供名称、正文、UTF-8 TXT / Markdown 导入，以及单集试做、多集短剧、AI 漫剧、真人感短剧四种制作起点。文件不超过 2 MB，正文不超过 100 万字符。
- 建立项目草稿复用正式建项接口，保存正文与起点后转入该项目的引导配置；不会由首页启动生成或扣费。
- 最近项目读取 SQL 权威记录，显示项目 ID、名称、类型、草稿/生产状态、版本和更新时间。支持名称/ID 搜索、全部/7 天/30 天、状态、类型组合筛选，以及稳定排序的服务端分页。
- 快速进入剧本、导演、生成和客户审片先选择实际项目；草稿进入继续配置。
- 最近生成任务和工作区任务中心读取真实 M06 任务，可按名称/任务 ID、状态、时间筛选、分页；打开项目任务时定位任务 ID。
- 灵感区域仅读取当前账号可访问的模板市场记录，空数据与服务失败分别反馈，不将制作起点视为模板授权。
- 首页偏好以表单设置区块显示、默认制作起点、默认时间范围和每页 3/6/9 项；保留已有扩展配置。

### 数据对象与业务规则

- 对象：`Project`、`GenerationTask`、`UserPreference`；模板使用既有市场对象。
- 项目和任务查询按可信租户、工作区及权限过滤；任务只关联当前工作区的非归档、已建项项目。列表不返回原文、预算、完整任务快照或供应商秘密。
- 草稿写入沿用建项幂等契约；偏好写入携带 `Idempotency-Key` 和 `version`。同键同内容返回原回执，旧版本或冲突返回 409。
- 偏好按租户、工作区、操作者隔离；更新、回执、审计及 outbox 同事务提交。并发更新只接受一个版本，失败回滚。

### 权限与数据范围

- 可信工作区上下文：`workspace.view`；首页项目读取：`project.view`；建草稿：`project.manage`。
- 生成任务还需 `generation.view`；模板需 `template.view`；其他一级模块按各自权限控制。
- 偏好读取与修改分别使用 `settings.view` / `settings.manage`，不以设置权限替代整个首页的项目权限。
- 服务端每次请求重新鉴权，客户端范围头不能选择租户或工作区；首页偏好携带的预期工作区与可信会话不一致时拒绝，防止旧页面误写入新工作区。写入留存操作者、对象、前后摘要、请求 ID 和结果。

### 页面状态与异常

- 加载、空项目、无匹配结果、无任务、模板为空、无权限和服务失败分别反馈；失败提供重试或切换工作区入口。
- 保存期间禁用重复提交。偏好冲突保留当前编辑，必须刷新最新版本后重试；网络重试复用对应幂等键。
- 数据看板一级入口按 `analytics.view` 开放，进入独立 CR-025 工作区统计；无权限时显示禁用原因。

### 接口依赖

- `GET /api/v1/session/context`
- `GET /api/v1/workspaces/{workspaceId}/creator-context`
- `GET /api/v1/workspaces/{workspaceId}/creator-home`
- `GET /api/v1/workspaces/{workspaceId}/generation-tasks`
- `POST /api/v1/projects/{projectId}/actions`（`new` / `saveDraft` 草稿保存与恢复）
- `GET /api/v1/account/preferences?resource=creator-home`
- `PUT /api/v1/account/preferences`
- 模板与任务详情复用既有市场和 M06 接口。

### 验收标准

1. 可信工作区下显示创作首页及固定一级入口，项目阶段只在项目内出现；无权限数据不泄露。
2. 输入或导入素材、选择制作起点后保存出唯一草稿，进入精确项目配置，刷新后正文、类型和集数仍一致。
3. 最近项目支持组合筛选、稳定分页及返回恢复；任务深链携带正确的工作区、项目和任务 ID。
4. 偏好保存和刷新一致，版本冲突、并发和重试不会丢失新配置或重复产生审计。
5. 空数据、服务失败、无权限和未开放入口有明确反馈，不显示伪造项目、模板、任务或费用。
6. 本地验证证据与真实 PostgreSQL、Java 身份、模型及联合验收分开登记；外部验收完成前保持开发中。
