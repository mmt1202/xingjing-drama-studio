### 页面目标

按剧本、资产、分镜、故事板和成片查看版本链、差异、锁定、回滚和来源。

### 入口、前置与退出

- 进入页面前必须解析当前工作区；项目内页面还必须解析项目、剧集或对象上下文。
- 入口可以来自所属一级模块、对象详情、任务/通知深链或具备权限的关联页面。
- 返回列表时恢复筛选、分页和滚动；深链跳转保留工作区与对象上下文。

### 页面区域、字段与操作

- 顶部区域必须展示页面标题、当前上下文、关键状态和主操作。
- 主内容区展示与 `版本记录` 直接相关的数据，不使用与业务无关的通用占位卡片。
  - 操作：查看版本记录
  - 操作：保存精确版本快照、冻结当前剧本或故事板、恢复历史内容、选用历史成片
  - 操作：同对象任意两版比较、下载受审计的 JSON 对比报告
  - 字段：对象 ID
  - 字段：名称
  - 字段：状态
  - 字段：来源、不可变内容摘要、当前修订、父版本与可执行操作
  - 字段：更新时间
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `ScriptVersion`、`AssetVersion`、`ShotVersion`、`StoryboardVersion`、`FinalVideoVersion`：原业务数据为唯一来源
  - `VersionCheckpoint`、`VersionCommand`、`VersionReport`：明确引用、稳定回执与审计记录
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - 项目入口 `project.view`；每类数据独立要求 `script.view` / `asset.view` / `shot.view` / `final.view`
  - 快照要求 `project.manage` 及来源读取权限；冻结/恢复另要求来源业务的 `.manage` 权限
  - 自定义成员按工作区权限与项目分配交集裁剪，窄对象范围保守拒绝
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：展示骨架屏并保留页面结构。
  - 空状态：说明无数据原因并提供当前用户有权限的下一步。
  - 异常态：区分无权限、无数据、服务失败和并发冲突。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。

### 接口依赖

  - `GET /api/v1/projects/{projectId}/version-history`、`/detail`、`/compare`、`/checkpoints`
  - `POST /api/v1/projects/{projectId}/version-history/actions`、`/reports`
- 通用依赖：`GET /api/v1/session/context` 获取当前用户、工作区、角色和功能开关。

### 验收标准

1. 具备权限的 账号所有者 能从规定入口进入 `版本记录`，页面上下文、标题和数据范围正确。
2. 无权限用户直接访问路由时服务端返回 403，页面不泄露对象名称、媒体地址或敏感字段。
3. 页面加载、空数据、处理中、成功、失败和并发冲突状态均有明确反馈和可执行恢复动作。
4. 所有写操作通过服务端校验、幂等和乐观锁；成功后重新读取的数据与提交结果一致。
5. 审计要求覆盖的操作可以按请求 ID、操作者和业务对象检索。
6. 页面接口失败不会丢失已保存数据，也不会产生重复任务、重复扣费或重复审批。

## 实现语义与验收边界

页面沿用公共创作者布局与原型四指标、左侧版本卡片/快照、右侧比较面板。服务端组合筛选、稳定分页、明确版本深链、返回筛选/滚动、操作草稿恢复和三语文案已接入。显式无效版本不会回退到其他内容；409 保留操作依据并提供显式放弃重读。

恢复剧本/资产/镜头/故事板会调用原领域服务追加修订，保留历史及下游冻结引用；剧本包含场景、段落和原文映射，故事板包含稳定镜头身份与顺序。冻结限于真实可冻结的当前剧本或故事板；故事板须配置真实质量策略。成片恢复只更新实际成片选用记录，不重新渲染。快照记录明确引用和完整源摘要，不冒充新增源版本。

`versionNumber` 是来源业务的版本号；成片显示关联冻结时间线修订，精确身份始终由 `versionId` 区分。`headRevision` 在成片上为选用记录修订。缺失的历史时间/操作者保留未知，今日指标仅统计可核验 UTC 时间；没有冲突事实源时显示未知。超过扫描/内容/差异上限返回明确错误，不截断后宣称完整。

迁移 `a9d4d7deeee9` 与 `XINGJING_VERSION_DATABASE_URL` 为部署前置；配置的项目和各业务来源须为同一权威数据库。不同物理数据库返回 503，不创建空镜像。真实 PostgreSQL 并发、Java 身份及规模验收尚未完成，需求保留开发中。

默认应用组合未注入生产 QualityPolicy，故事板冻结保持不可用；需要在组合处注入可信策略，不存在仅通过环境变量开启的配置。
