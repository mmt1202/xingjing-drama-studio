### 页面目标

为抖音、快手、视频号、小红书生成封面、标题字区和 A/B 候选。

### 入口、前置与退出

- 进入页面前必须解析当前工作区；项目内页面还必须解析项目、剧集或对象上下文。
- 入口可以来自所属一级模块、对象详情、任务/通知深链或具备权限的关联页面。
- 返回列表时恢复筛选、分页和滚动；深链跳转保留工作区与对象上下文。

### 页面区域、字段与操作

- 顶部区域必须展示页面标题、当前上下文、关键状态和主操作。
- 主内容区展示与 `封面生成` 直接相关的数据，不使用与业务无关的通用占位卡片。
  - 操作：查看封面生成
  - 操作：更新封面生成 配置
  - 操作：保存并审计变更
  - 字段：对象 ID
  - 字段：名称
  - 字段：状态
  - 字段：配置值
  - 字段：更新时间
- 列表支持服务端分页、稳定排序和组合筛选；详情显示对象 ID、版本和更新时间。

### 数据对象与业务规则

  - `CoverPlan` / `CoverCandidate` / `CoverVariant` / 不可变 `CoverSelection`
  - 方案绑定明确成片版本、剧集和平台；评分与评估说明由人填写，不代表点击率或合规结论。
- 所有查询按租户和权限范围过滤；跨对象引用校验同一工作区或明确授权关系。
- 写入携带 `Idempotency-Key`；更新携带对象 `version`，冲突返回 `409 VERSION_CONFLICT`。

### 权限与数据范围

  - `settings.view`
  - `settings.manage`
  - `project.view` / `final.view`；生成另需 `generation.view/manage`，应用另需 `export.manage`。自定义成员仅接受当前完整项目范围。
- 前端可见性不能替代服务端鉴权；权限变化后下一次请求立即生效。
- 所有新增、修改、提交、审批、导出、删除或高风险动作记录操作者、时间、对象、变更前后摘要、请求 ID 和结果。

### 页面状态与异常

  - 加载态：展示骨架屏并保留页面结构。
  - 空状态：说明无数据原因并提供当前用户有权限的下一步。
  - 异常态：区分无权限、无数据、服务失败和并发冲突。
- 网络重试不得重复提交写操作；恢复后重新读取服务端最终状态。

### 接口依赖

  - `GET /api/v1/projects/{projectId}/cover-plans/catalog`
  - `GET/POST /api/v1/projects/{projectId}/cover-plans`
  - `GET /api/v1/projects/{projectId}/cover-plans/{planId}`
  - `POST /api/v1/projects/{projectId}/cover-plans/{planId}/actions`
  - `GET /api/v1/projects/{projectId}/cover-plans/{planId}/candidates/{assetId}/content`
- 通用依赖：`GET /api/v1/session/context` 获取当前用户、工作区、角色和功能开关。

### 验收标准

1. 具备权限的 账号所有者 能从规定入口进入 `封面生成`，页面上下文、标题和数据范围正确。
2. 无权限用户直接访问路由时服务端返回 403，页面不泄露对象名称、媒体地址或敏感字段。
3. 页面加载、空数据、处理中、成功、失败和并发冲突状态均有明确反馈和可执行恢复动作。
4. 所有写操作通过服务端校验、幂等和乐观锁；成功后重新读取的数据与提交结果一致。
5. 审计要求覆盖的操作可以按请求 ID、操作者和业务对象检索。
6. 页面接口失败不会丢失已保存数据，也不会产生重复任务、重复扣费或重复审批。

## 当前实现边界（2026-10-23）

- 专用封面工作台沿用创作者公共布局，支持方案筛选/分页、成片/平台固定绑定、提示词、画幅和百分比标题参考区。
- M06 真实生成接入、受控图片关联与鉴权预览；图片大小/哈希/实际格式/尺寸不匹配时拒绝。模型或计费未配置不产生模拟任务。
- 多组图片、标题、简介和标签独立保存；支持并排比较、人工评分及说明、推荐、选用与应用。更新组合会清除该组合的旧评估及相关选用状态，已应用快照保持不可变。
- 标题和参考区是布局预览；交付保存原始图片及独立文案/布局清单，不声称已将标题绘制到图片中。
- 发布深链保留成片、剧集、目标和选用记录。M09 带封面 ZIP 要求审核服务确认精确封面与文案 digest；缺失或错误回执明确阻断。小红书方案可保存，但 M09 尚不支持其正式发布目标，不映射为其他平台。
- 所有写入带版本和稳定幂等键，权限、可信作用域、审计和 outbox 同事务；失败保留草稿，409 提供显式放弃重读。
- 本地实现和验证不代表真实服务联合验收；详见 EV-M18-COVER-002。
