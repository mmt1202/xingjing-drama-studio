#### 页面目标与区域

工作区内按项目、剧集、模型、成员查看实际生产、任务和费用。沿用原型顶栏、四项指标、近六个月产出、模型调用、成员贡献、项目状态、效率和成本区域，增加可追溯的统计明细与来源说明。

- 周/月/季度/全部范围按 UTC 自然窗口计算；组合筛选写入 URL，列表稳定排序、服务端分页，项目详情跳转保留对象上下文与返回筛选/滚动。
- 项目数与项目状态是当前可见项目范围；成片集数按项目和剧集去重，同集重渲染不重复算集；镜头只统计对应成片冻结时间线内的镜头。
- 任务成功率为成功 /（成功 + 失败 + 超时），取消和处理中单列，无终态样本显示不可计算；任务按创建时间入窗口。平均耗时只计算有起止证据的成功任务，并显示样本数，不能解释为完整制作周期。
- 模型/成员贡献采用有记录的任务归因，未知归属单列。技术重试不等于创意返工；成片与交付缺少模型/成员因果归因时不伪造关系。正式发布包不等于外部平台已发布。
- 本期截至读取时刻，环比上一完整 UTC 自然周期；上期为零或无样本时不计算百分比。日均按已跨自然日（含今日）计算，全部范围无明确起点时不计算日均。
- 费用按结算时间统计权威已结算金额，当前冻结单列；币种分别显示，金额以十进制整数字符串传输，避免浮点误差。失败与重试费用是总额子集，不能重复相加。
- 报告由服务端按同一组合筛选及完整匹配分组生成，不只导出浏览器当前页；包含统计范围、截止时间、口径与币种，执行 CSV 单元格防注入和导出上限。
- 默认时间范围和默认维度以操作者、租户和工作区隔离保存；配置失败保留输入，409 提供显式重读，导航保护未提交更改。新增界面文本同时提供 zh/en/vi。

#### 数据、权限与协议

- 统计从现有项目、生成/音频/渲染任务、成片冻结版本、结算与正式交付记录读时计算；不把演示数字、预估费用或供应商回报重复计入，不宣称已有完整事件仓库。
- `GET /api/v1/analytics/dashboards/creator`：聚合统计、筛选选项、趋势、覆盖说明及明细分页。
- `POST /api/v1/analytics/dashboards/creator/export`：同范围 CSV、稳定命令回执、审计及 outbox 同事务。
- `GET/PUT /api/v1/account/preferences` 的 `data-dashboard` resource：默认范围/维度，版本 CAS、幂等回执与审计；独立校验 `analytics.view/manage`，不能以设置权限绕过。
- 看板拒绝 API Key，验证预期工作区；owner/admin 和平台管理员按工作区授权，其他角色还需有效项目授权，工作区与项目各域权限取交集限制相应事实来源；仅非空且每项均为 `project:{当前项目ID}` 的明确整项目数据范围纳入，未知/通配/窄对象或混合范围不提升为整项目。筛选选项、分母、明细与导出共用可见范围，撤权后不能重放旧范围导出。
- 聚合依赖同一物理数据库中的正式来源表；明确配置为不同数据库或不可确认的间接目标时返回 503，不读取空镜像冒充真实零值。更换 driver/账户不等于切换数据库，schema 与目标参数仍参与校验。
- 迁移 `87b2b5beccc7` 增加导出回执/审计并为系统 owner/admin 合并分析权限；保留其他权限、自定义角色和 member，更新新工作区身份同步函数。未应用生产数据库。

#### 状态与验收边界

加载、空筛选、无权限、来源不可用、超出扫描/导出上限、网络错误和配置版本冲突均明确反馈；来源失败不以零值替代真实统计。接口和浏览器的实际验证结果见证据文档，模块保持 0/11 已验证。

仍需真实 PostgreSQL/Java 部署、大规模查询及 A1 联合验收。跨库聚合与窄对象范围统计未实现，保持明确拒绝或排除。完整制作周期、业务返工率、成员镜头作者归因、在线人数和外部发布指标缺事实源，维持明确不可观测状态；本轮未扩展成自定义报表平台或永久事件/快照仓库。
